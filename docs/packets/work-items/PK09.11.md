Use `ItemInfoAction::ForceUpdate` for source nonzero-val2 callers; a data assignment or owner maintenance refresh must not accidentally toggle. Raw name spelling is not numeric-ID equality; identification, quantity, damage, prices, wear, bind and expiry are not key fields.
