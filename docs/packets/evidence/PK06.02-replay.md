# PK06.02 — selected-profile guild member status replay

Date: 2026-11-04. Status: production framing/decode/dispatch implemented; PK06.03 UI/map propagation remains open; PK48 review pending.

## Change

Added `0x01F2` at fixed size 20 while retaining legacy `0x016D` at size 14. `ro::guild::ReadWindowPacket` requires exactly 20 bytes and status 0 or 1 before mutation, resolves an existing member by account and character IDs, updates online state and gender/hair fields, and recalculates the online count. A notice never creates a member. The production guild router now includes 01F2.
