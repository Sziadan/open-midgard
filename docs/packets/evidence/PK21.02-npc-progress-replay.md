# PK21.02 NPC progress wire replay

The production map framer and router accept fixed `02F0` and `02F2`. A start creates a 60×6 gauge for the existing local player, ignores the wire color, and starts or replaces a deadline using the duration in seconds. The mode owns this gauge separately from skill casting gauges. A duration beyond the signed millisecond range is rejected before changing the gauge.

At the inclusive deadline the bar reaches 100 percent. On the first update after the deadline, or when an active `02F2` arrives, the mode clears progress and sends the two-byte `02F1`. Repeated aborts and subsequent timer updates have no acknowledgement. The mode updates the timer independently of screen projection.

The focused replay covers start, replacement, exact expiry boundary, abort, duplicate suppression and literal reply bytes. It projects the NPC gauge above an ordinary cast gauge and checks that the Qt adapter selects the NPC gauge and reports the expected geometry and duration. Aborting the NPC gauge leaves the cast gauge available. [Selected contract](PK21.01-npc-progress-contract.md)
