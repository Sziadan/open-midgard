# PK46.02 — guild-alliance reply request 0x0172

Date: 2026-11-05. Status: client prompt branch, selected parser and alliance-state decision path are source-traced. Permission/correlation semantics and cross-server result ordering need stronger review and replay. No row closed.

`Commerce::Action` handles a pending `prompt` when `promptKind == "alliance"` by sending a fixed 10-byte `0x0172` frame: prompt ID u32@2 and answer u32@6 (`1` accept, `0` decline). A failed send preserves the prompt; successful send clears `promptKind`. The neighboring guild reply uses 0x016B and friend reply uses 0x0208, so their different correlation fields are not merged into this leaf.

The selected final registry assigns length 10 to `clif_parse_GuildReplyAlliance` with positions `2,6,0` (`PK01.02-server-registry-final.csv:133`). The parser reads account ID@2 and answer@6 and calls `guild_reply_reqalliance` (`src/map/clif.cpp:14631-14636`). The prompt handler stores the inviter account ID and guild context when receiving `0x0171` (`GameModePacket.cpp:7307`); the reply function resolves the supplied account ID to an online player and checks that the recipient's pending inviter guild matches that player's current guild (`src/map/guild.cpp:1915-1927`). The shown check does not compare the supplied account ID with the stored pending inviter account ID, and this function contains no explicit rank/leadership check; independently review whether another gate enforces those rules before treating the correlation as correct. Missing inviter returns result 3 to the recipient; decline clears pending alliance fields and sends result 3 to an online inviter. Acceptance checks both guilds and alliance-capacity limits, may enqueue removal of existing opposition relations, then submits the new relation through `intif_guild_alliance` (`guild.cpp:1928-1963`). The resulting relation update is asynchronous. Replay inviter disappearance, stale/altered account IDs, permission, decline/accept capacity failures, opposition replacement and update ordering before closure; no row closed.
