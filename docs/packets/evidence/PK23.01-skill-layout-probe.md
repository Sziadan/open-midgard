# PK23.01 selected skill layout probe

Compiled the [layout probe](PK23.01-skill-layout-probe.cpp) against the original local server headers. The assertions check the effective packet version, selected opcode and packed size, field offsets, and relevant field types. The `011F` emitter writes its frame manually. Its size and fields are checked separately against the packet registration and writes in [the contract](../contracts/PK23.SKILL-RECEIVE.md). The `0115` structure exists in the headers while its server emitter is inactive.

```powershell
$server = 'C:/Users/sziad/source/repos/rathena-master'
$mingw = 'C:/Qt/Tools/mingw1310_64/bin'
$probe = 'build-mingw-preset/packet-audit/pk23-skill-layout-probe.exe'
New-Item -ItemType Directory -Force (Split-Path $probe) | Out-Null
& "$mingw/g++.exe" -std=c++17 "-I$server/src" "-I$server/3rdparty" `
    "-I$server/3rdparty/libconfig" "-I$server/3rdparty/rapidyaml/src" `
    "-I$server/3rdparty/rapidyaml/ext/c4core/src" "-I$server/3rdparty/mysql/include" `
    docs/packets/evidence/PK23.01-skill-layout-probe.cpp -o $probe
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
$env:Path = "$mingw;$env:Path"
& $probe
```
