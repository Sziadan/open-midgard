## PK47.04-BOSS-MAP-INFO

The selected server's `clif_bossmapinfo` sends `0293` from `SC_BOSSMAPINFO` in `src/map/status.cpp`. Status start sends the named position or respawn notice. Periodic updates send the position or respawn notice. Type 0 reports that no boss exists. The packed definition in `src/map/packets.hpp` is 70 bytes, with type at 2, position at 3 and 7, minimum respawn hours and minutes at 11 and 13, maximum fields at 15 and 17, and a 51-byte name at 19. The selected emitter only fills the minimum pair.

The selected client handler in `HighPriest.exe.c:380597` clears the previous position, records it for types 1 and 2, and announces types 0, 2, and 3. Type 3 with a zero-hour, one-minute value uses the special imminent-respawn notice. The rebuild frames and routes the feed, shows localized notices in chat, projects a shared native and Qt map marker, and clears the marker on map change. Production replay exercises all four types, an unknown type, marker movement, and the notice branches.

The reference uses a 12×12 textured marker from `유저인터페이스\map\bossmonster.bmp` (`HighPriest.exe.c:332390`, virtual address `0x712248`). The rebuild uses its existing white marker rendering. Reference bitmap and animation, overlay notice placement, and live Convex Mirror verification remain open.
