## Production paths and repairs

The new Windows/Qt test links the actual client runtime. Native frames execute `UIRoMapWnd::OnProcess -> DrawToHdc -> DrawWindowContents`. Qt frames use `QtUiStateAdapter::syncMinimap -> PopulateMinimapState -> GetDisplayDataForQt`, the actual `BuildQtMinimapImage` image-provider branch and the production `GameOverlay.qml` repeater captured by QQuickView. `syncGameplay` uses the same narrow `syncMinimap` entry point. The test supplies a synthetic BMP, bundled UI font and genuine world attribute bounds; it does not replace marker geometry with fabricated QML data.

Actual captures exposed two bugs and supplied failing evidence before repair:

1. Stored packed RGB 0x0A31B8 appeared as native **#b8310a**, while Qt correctly drew **#0a31b8**. Native was passing RGB bits straight to COLORREF. It now converts channels explicitly at the native marker boundary.
2. A native marker at cell X=0 painted left of the map rectangle; QML already clipped it. Native now saves/intersects/restores the map clip around marker painting. The edge pixel check fails before this repair and passes afterward.

Diagnostic pre-fix captures and logs are preserved with the accepted images and source/binary hashes. A separate test-setup issue was resolved: the normal app deployment contains qwindows, while the offscreen test requires the matching Qt kit's qoffscreen plugin. CMake derives that test-only plugin path from the selected Qt package. Application deployment behavior is unchanged. Bundled Noto Sans is registered for a legible synthetic scene.

Each scene captures a native PNG and a production-QML PNG, with exact expected dot/background pixels at independently calculated fixture coordinates. The native path includes its normal OnProcess cache update. The adapter marker count and absence of stale pixels are asserted as well.

- Online; stationary full-roster refresh; continuous online movement; movement back.
- Offline; online without fresh position; fresh position; removal sentinel.
- Full roster loss; other map; rejected position on another map.
- Guild over party; player over guild/party; left map edge with no out-of-bounds dot pixels.
- Actual map-change handler; successful/failed injected reconnect through that handler; real LoginMode exit session boundary.
