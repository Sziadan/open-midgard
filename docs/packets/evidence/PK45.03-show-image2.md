Date: 2026-11-04. Status: fixed framing, field extraction and shared cutin-state update traced; selected-server contract traced; asset behavior and rendering remain open. No rows closed.

Opcode 0x01B3 is registered with fixed size 67 and routed to `HandleShowImage2`. The handler requires data and at least 67 bytes, copies the 64-byte field at offset 2 into a NUL-terminated local name, and reads type byte@66. Type 255 maps to -1. It then sends game-mode message 113, which uses the same `UpdateShowImageInfo` path as opcode 0x0145: store name/type and append `.bmp` unless `.bmp` or `.BMP` is already present. The frontend cutin adapter consumes this state. No reply is sent and the handler does not validate the opcode locally.

Compared with 0x0145, this packet has a registered fixed 67-byte size and a 64-byte name field instead of the other handler's 16-byte field and missing size-table entry. The coverage ledger classifies 0x01B3 as an S2C map packet but leaves semantic review open.
