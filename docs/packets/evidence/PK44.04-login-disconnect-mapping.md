## Source contract

The selected `PACKET_SC_NOTIFY_BAN` layout is three bytes: little-endian opcode `0x0081` followed by a one-byte result. `src/login/loginclif.cpp::logclif_sent_auth_result` sends result 1 when the login service is stopped, connection-group policy rejects the account, or no character server is online. Result 8 is sent when the account is still marked online on a character server. The source comment also names result 2 (“someone has already logged in”), but this snapshot has no call site that emits 2; retain the numeric fallback for that value pending an emitter trace.

Selected-source hashes: `src/login/loginclif.cpp` `A0EEA56F5A41286674AE27CAAD5B57E192B298E20C0FDDC38F015B0C2ECE5E3F`; `src/common/packets.hpp` `07B47B66A41ED05433F852E399BA1D714BA728074F76633AD77BC2F7720D79EF`.
