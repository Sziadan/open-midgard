# PK45.03 — ground-item entry variants and world sync

Date: 2026-11-04. Status: client layouts and selected-server variant selection/fields traced. Resource/render parity and replay remain open. No rows closed.

## Entry variants

The current receive profile exposes 0x009D existing ground item and 0x009E dropped ground item; the packet-size table fixes both at 17 bytes and both route to `HandleGroundItemEntry`. The common fields are object ID u32@2, item ID u16@6, identified byte@8, and tile X/Y u16@9/@11. For 0x009D, amount u16@13 and subcell X/Y bytes@15/@16. For 0x009E, subcell X/Y bytes@13/@14 and amount u16@15. The handler upserts the logical `GroundItemState`; only the dropped variant sets `pendingDropAnimation`.

## World synchronization

`SyncGroundItemsToWorld` runs in the game-mode update path. It removes world `CItem` objects whose AID is no longer in the logical ground-item map, creates missing items, updates item identity/position/display and resource names, computes world coordinates from map tile and subcell offsets, and invalidates the billboard when item resources change. A pending drop animation triggers once and clears its flag. Together with the 0x00A1 disappearance evidence, this traces the logical spawn/update/remove lifecycle through the world item list.

## Open verification

## Selected server ground-item entry variants (2026-11-04)

The selected server uses both client layouts. Existing floor items are sent through `clif_getareachar_item` as fixed `0x009D` records containing object ID, client item ID, identify flag, coordinates, amount, and subcell offsets; that path sends SELF to the entering session. Newly dropped floor items use `clif_dropflooritem` and fixed `0x009E` records, with amount after the subcell offsets, broadcast in AREA. Both emitters source the fields from the same floor-item record, but serve different synchronization events and preserve the client-observed variant-specific offsets.

The `0x009E` path can later add drop-effect metadata under newer packet versions; that extension is not active in the selected 2008 profile. Resource lookup, subcell/render parity, and replay of area entry versus drop ordering remain open. No discovery row is closed.
