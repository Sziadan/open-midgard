# PK29.03 elemental snapshot

The selected rAthena build uses `PACKETVER=20080910` in `src/custom/defines_pre.hpp`. The packet registration in `src/map/clif_packetdb.hpp` lists elemental `081D` from `20100309`, but `clif_elemental_info` writes its 22-byte frame directly. A character with a saved `ele_id` requests the elemental in `pc.cpp:2466`. `elemental_data_received` in `elemental.cpp` can spawn it and send the snapshot. Refresh and map-change paths in `clif.cpp` can send it again.

Receive profile 23 frames `081D` and stores the elemental GID and four unsigned HP/SP values in a separate map-scoped snapshot. Map handoff clears it. It does not assign homunculus or mercenary ownership. `ElementalSnapshotReplay` checks fragmentation and the following `0080` frame through the production receiver, then checks field decoding and ownership isolation through the default router. `CompanionIdentityReplay` checks reset.

The `081E` update sender is gated at `20100309`. `elemental_delete` uses `CLR_OUTSIGHT`, including when called from `elemental_dead`. That reason is shared with visibility removal, so this checkpoint only retires the snapshot on map reset. Live elemental restore, dismissal handling, and newer companion variants remain open.

The homunculus HP/SP delta `07DB` is gated at `20090610`. The current MAIN source emits legacy `022E`, `0235`, and `0239` under the selected date. [Homunculus upgrade evidence](PK28-homunculus-skill-upgrade.md)
