## Team state and presentation

- `02DD` is 32 bytes. Area and single-recipient emblem senders write actor AID at 2, a 24-byte name at 6, and the low 16 bits of `bg_id` at 30. These emitters run on actor entry and area sight when the subject has a team and the map has `MF_BATTLEGROUND`. The reference reads only the low byte of the camp field and branches on local AID. Use the full selected wire field for team comparison so team IDs that share a low byte remain distinct. Trace the opposing-camp word display through the reference actor owner, including hidden actors and admin exclusions. Keep guild emblem identity and team identity separate.
- `02DE` is six bytes with two signed 16-bit camp scores. The map-wide update is sent from the score script path and the self update from map entry. The reference stores both scores and writes a system chat line in COLORREF 13158600. Score receipt alone does not establish local team membership.
- `02DF` is 36 bytes with account ID, 24-byte name, class and signed X/Y at 2/6/30/32/34. The server sends within the same map to teammates other than the subject. The removal sender writes both coordinates as -1 and clears name and class. Reference mode message 69 applies remote minimap positions. Use a team-specific marker collection with shared native and Qt projection and remove it on the sentinel and scene retirement.
- `02E0` is 34 bytes with account ID and name at 2/6 and HP and maximum HP at 30/32. The server uses actual HP when maximum HP fits signed 16 bits, otherwise it writes a scaled value with maximum 100. Preserve the ratio. The reference updates the visible actor through message 34 and excludes the mercenary. The later 14-byte `0A0E` variant drops the name and uses 32-bit HP fields under `PACKETVER >= 20140613`. It appears in the historical catalog and is absent from the selected registry.

## Chat and lifecycle

`02DB` is the variable-length formatted team chat request. The existing buffered chat sender uses the selected battle opcode when mode message 271 owns the submission. The selected server validates the sender and text through `clif_process_message`, then `bg_send_message` requires a nonzero team and a matching team record. Reference `/battlechat` toggles the sender mode. Trace command reachability and clear it with the local battleground state.

`02DC` contains the declared length, source AID, 24-byte name and formatted text at 0/2/4/8/32. Team broadcasts include server notices with zero AID. The reference applies ignore filtering, chat visibility options, an actor bubble when the speaker is present, and chat logging. Current code displays the text but has no membership or lifecycle owner. Verify ordinary and server senders, ignore behavior, special name color, and team chat routing without changing party or guild chat.

The server removes the departing member's marker before clearing its team ID. It can emit a team-wide leave notice, but it does not send a dedicated local camp reset from `bg_team_leave`. Reset local scene state on map handoff and mode exit. Verify scripted leave on the same map before treating a remote marker removal or formatted leave message as authoritative local membership state.
