## Change

Added `PopulateGuildMemberPresenceData`, used by `PopulateGuildWindow`, to pass online, gender, hair style, and hair color into the QVariant member row. `RoGuild.qml` already reads `modelData.online` for its visible Online/Offline label; gameplay sync rebuilds `guildWindow` from current session state. No guild UI redesign was needed.

Extended `HandleGuildWindowPacket` so an offline 01F2 notice removes the account's stale map-position marker, matching the existing 016D offline cleanup. Coordinates remain managed by separate 01EB position notifications. The notice updates an existing guild member only and cannot create a row or marker.
