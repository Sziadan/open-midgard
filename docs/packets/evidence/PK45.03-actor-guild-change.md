# PK45.03 — actor guild ID/emblem version change

Date: 2026-11-04. Status: client path and selected 20080910 emitter layout/fields traced; emission lifecycle, visual/cache refresh, and replay remain open. No rows closed.

The size table fixes 0x01B4 at 12 bytes and the router maps it to `HandleChangeGuild`. The handler requires a data pointer, at least 12 bytes, and a live world. It reads actor identifier u32@2 (AID in the selected server packet), guild ID u32@6, and emblem version u16@10. If that GID equals the local character GID or account AID, it updates the local guild cache identity/version; when character or guild ID changes, that cache is zeroed first. No guild name or permissions are present in this packet.

The handler resolves the packet identifier through `ResolveSkillPacketActor` and calls `SetGuildInfo` if an actor exists. The resolver accepts local AID/GID aliases and otherwise looks up a world actor by AID. `SetGuildInfo` allows player characters and a short set of guild-actor jobs (1285–1287 and 722); guild ID must be positive and emblem version positive except for job 722. Job 722 may explicitly clear its guild/emblem values when guild ID is zero. Other invalid values and non-guild actor types are ignored.

## Local snapshot and actor eligibility follow-up (2026-11-04)

`HandleChangeGuild` resolves the packet identifier as an actor, and separately treats it as a local-player match when it equals either the session character GID or account AID. On a local match it reads guild ID u32@6; if the cached local-guild character ID or guild ID differs, the whole local-guild record is cleared, then character ID, guild ID, and emblem version u16@10 are assigned. This path can update the local snapshot even when no world actor resolved. It does not populate guild name, level, member list, or skill data.

For a resolved actor, `SetGuildInfo` accepts player characters and jobs 1285–1287 or 722. It rejects guild ID below 1 and emblem version below 1 except for job 722; job 722 with guild ID zero explicitly clears its guild/emblem fields. Other accepted updates change only actor guild ID and emblem version. The packet path does not itself clear guild windows or guild-skill state.

This completes the client-side snapshot/eligibility branch audit. The selected emitter confirms the field is AID. Remaining open items are the trigger/call-site lifecycle, visual/cache refresh consequences, and replay. No discovery row is closed.
