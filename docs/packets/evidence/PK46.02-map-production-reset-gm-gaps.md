## PK46.02-CHARACTER-RESET

The selected client decompilation parses `/resetstate` as talk type 61 and `/resetskill` as type 62. The talk dispatcher sends mode message 155 with selector 0 or 1. The selected server registers four-byte `0197` and passes selector 0 to `resetstat` and selector 1 to `resetskill` through its administrative command authorization path. The production chat replay captures both complete frames, rejects an invalid selector, and checks failed transport. Live permission, stat and skill updates remain open.

## PK46.02-GM-HIDE

The selected client parses `/hide` as talk type 88, then calls mode 157 with the literal 64. The selected server registers six-byte `019D`. Its parser invokes the permission-checked `hide` command, which toggles server option bit 64 and emits the actor option update. The server treats the request as a toggle, so the client sends it only on explicit input. Production replay captures the frame, failed transport, and local actor updates from injected `0229` replies. Live permission checks and visibility to other players remain open.

## PK46.02-MAP-CELL-COMMAND

The selected `/changemaptype` and `/cmt` commands use talk type 63 and mode message 156. The eight-byte `0198` contains X and Y at offsets 2 and 4. The selected client converts the third argument to 0 or 1 at offset 6. The port rejects malformed numbers and coordinates that cannot fit the wire field. The selected server checks `PC_PERM_USE_CHANGEMAPTYPE`, sets terrain on the current map, then broadcasts `0192`. The local terrain changes through that inbound path. Replay checks both aliases, argument rejection, send failure, and walkability before and after the update. Live permission and second-client behavior remain open.
