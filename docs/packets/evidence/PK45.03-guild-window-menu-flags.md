## Selected server flags and Qt tab consumers (2026-11-04)

The pinned server documents the menu bit assignments: `0x01` member manager, `0x02` positions, `0x04` skills, `0x10` expulsion list, `0x80` notice; `0x40` is explicitly unknown. Its emitter sends `0xD7` for guild masters and `0x57` for members to SELF, so the member mask omits only the notice bit while both masks include 0x40. The Qt guild panel binds tabs to 0x01/02/04/10, treats basic info and one additional tab as always enabled, and gates notice editing on both master state and 0x80. It does not consume 0x40. The packet parser replaces the mask, so QML bindings should see the update through the shared state; actual live refresh/replay remains unverified.
