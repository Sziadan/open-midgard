# PK39.02 MVP rewards

The selected MAIN `20080910` server uses `clif_mvp_item`, `clif_mvp_exp`, `clif_mvp_effect`, and `clif_mvp_noitem`. The fixed map frames are `010A` (four bytes, item ID at 2), `010B` (six bytes, 32-bit EXP at 2), `010C` (six bytes, winner AID at 2), and `010D` (two bytes). The effect is sent to the area. The other three are sent to the winner. `010B` is replaced by a colored text notice on later server profiles.

`Ref/GameModePacket.cpp` cases 266–269 route the item and EXP notices to cyan chat and the dropped-item notice to red chat, with the chat show/expand message. Item presentation uses the unidentified display name and the prefix alone. The installed `data.grf` message table places item, EXP prefix and suffix, and the weight-limit notice at indices 143, 145, 146, and 147. The client uses these entries when available. `010C` routes to actor message 36, which already creates and attaches effect 68. Reward notices leave inventory and EXP ownership with their normal update packets.

Replay concatenates all four frame types and a subsequent broadcast, checks the reward notice colors, maximum signed EXP amount, and local, remote, and missing actor routing. Live boss reward and rendered effect acceptance remain open. Ranking families remain in PK39.02.
