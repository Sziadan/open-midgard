## User action to sender

`UIStorageWnd::OnButton` handles `kButtonIdClose` by sending `GameMsg_RequestStorageClose`. `GameMode` dispatches that message to `RequestCloseStorage`, which rejects the request unless local storage is open. The helper fills the close packet, sends its full structure, logs and returns the send result. It does not clear local storage state before a server result.

## Client layout and profile

Serialization is two bytes total: opcode at offset 0, width 2.
