# PK45.03 — guild member roster 0x0154

Date: 2026-11-04. Status: variable framing, roster replacement and consumed row fields traced; row semantics/profile contract remain open. No rows closed.

Opcode 0x0154 uses variable-length framing and routes through `HandleGuildWindowPacket` to `ReadWindowPacket`. The parser selects 104-byte rows and requires a four-byte header plus an exact payload multiple before clearing `state.members`. Each row populates account u32@0, character u32@4, exp u32@18, position u32@26, job u16@14, level u16@16, online=`u32@22 != 0`, and bounded name[24]@80. Other row bytes are not consumed by this initializer; gender/hair style/hair color remain their struct defaults. A valid header-only packet clears the member list.

After successful parsing, the outer handler performs its common local position-derived permission/title refresh. This branch does not recalculate the separate `state.online` summary count and does not mark the summary loaded. No network reply is sent. Coverage routing remains provisional.

Open work: confirm the roster row schema, skipped fields and snapshot semantics against the selected server; establish whether online count is expected to update separately; replay empty/aligned/malformed rows, duplicate identities, local-member position and UI state. ## Selected server roster emitter follow-up (2026-11-04)

The pinned `clif_guild_memberlist` emitter confirms the active PACKETVER 20080910 variant: `0x0154` variable frame with a four-byte header and 104-byte packed rows. Each row contains AID, GID, hair style, hair color, gender, job, level, contribution experience, online state, position ID, intro[50], and name[24], in that order. The client consumes the same offsets for AID/GID, job/level, experience, online state, position and name; omitted appearance/intro fields are currently unused by its roster model. In this profile the intro is explicitly zero-filled and the name is copied from server member state. The emitter skips zero-AID slots, counts only emitted rows in packet length, sends SELF, and returns without a packet for a session without a guild.

This validates the selected row schema and online-state meaning from pinned emitter/struct sources. Independent fixture/replay, duplicate identity behavior, and whether guild summary online count should be refreshed by a roster update remain open. No discovery row is closed.
