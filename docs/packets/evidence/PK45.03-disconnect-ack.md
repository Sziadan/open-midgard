# PK45.03 — disconnect acknowledgement

Date: 2026-11-04. Status: fixed framing, pending-action/result decisions and effects traced; selected-server result semantics and teardown replay remain open. No rows closed.

The size table fixes 0x018B at 4 bytes and the router maps it to `HandleDisconnectAck`. The handler reads result u16@2 and combines it with the current pending action through `DecideDisconnectAck`:

- Result 1 with any pending action is treated as refused: pending action is cleared and a red system chat event is pushed.
- Result 0 with `ExitToWindows` is accepted: pending action is cleared, `m_pendingReturnToCharSelect` is reset to zero, the connection disconnects, and the mode manager quits.
- All other result/action combinations are logged and ignored, leaving pending state unchanged.
