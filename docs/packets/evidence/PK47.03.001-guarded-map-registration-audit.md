Date: 2026-11-04. Status: completed source-registration trace; protocol identity/disposition remains unresolved.

## Catalog provenance correction

`historical-catalog.csv` is generated from four packet definition files in one current rAthena source snapshot, not from multiple server revisions. `tools/audit_packets.py` scans `src/map/clif_packetdb.hpp`, `src/map/packets.hpp`, `src/map/packets_struct.hpp`, and `src/common/packets.hpp` at lines 268–276. It collects numeric definitions across compile-time profile guards; the catalog does not preserve each definition’s guard or server revision. Thus “outside the 990-row union” means absent from this selected-config client/server inventory, not proven to be from an earlier server release.

## Source-registration scope

Among 445 catalog opcodes outside the 990-row union, **232** have active (non-commented) source occurrences in `src/map/clif_packetdb.hpp`, totaling **297** guarded registration lines. Every registration has a preprocessor condition context. **212** occurrences use `parseable_packet` with a named parser; **85** use `packet` with no parser. At the opcode level, 152 have parser registrations, 81 have a null-parser registration, and one has both kinds. None appears in the selected final map registry.

The CSV records each opcode, every registration line and guard context, length, parser when present, and the selected registry observation. ## Limits

This establishes source registration declarations and their selected-config absence. It does not validate handler bodies, feature sender reachability in an original client, full packet layouts where only raw lengths are listed, or the semantics of null-parser registrations. Accordingly all 232 rows remain `UNRESOLVED`, with no discovery rows manufactured and no semantic classification changed. The other 213 catalog-only opcodes do not have active packetdb source lines matched by this scan and remain open for source-definition review.

No runtime files changed and no runtime test/build was applicable. This child advances source evidence while preserving the open rows for later PK47.03 work and PK48 review.
