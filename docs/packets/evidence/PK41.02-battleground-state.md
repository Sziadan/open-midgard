# PK41.02 selected battleground state

The production map router receives `02DD` camp identity, `02DE` scores, `02DF` teammate positions, and `02E0` HP using the MAIN 20080910 layouts. [Wire and source evidence](PK41.01-selected-battleground-inventory.md)

`02DD` keeps the full 16-bit camp for the local AID and for a visible remote actor. `02DE` stores the two signed scores and writes the original system notice. Score-only updates leave membership at its previous value. The two cases use separate state.

`02DF` adds or moves a teammate dot by AID, including when the actor is outside sight. It ignores the local AID and removes the marker on the paired `(-1, -1)` sentinel. Native and Qt minimaps draw the team dots with the same cyan accent. Cyan is a client presentation choice pending comparison against the original client. The party and guild lists have their own lifetimes.

`02E0` sends the signed wire HP pair to actor message 34 for an existing actor other than the owned mercenary. The selected server emits this for nearby teammates and uses a maximum of 100 when scaling large HP totals. The receiver preserves that pair and discards invalid negative HP or nonpositive maxima before passing values to the unsigned gauge. Valid map transitions and mode cleanup retire camp, scores, and teammate dots.

`Ref/GameModePacket.cpp::Zc_Battlefield_Notify_Campinfo` calls `CGameMode::MakeWordDisplayWnd` for an opposing actor, with hiding, burrow, special hiding and Gravity AID checks. `Ref/GameActor.cpp::DeleteWordDisplayWnd` retires the actor-owned window. `Ref/UIControl.cpp::UIWordDisplayWnd::OnDraw` loads the path at `HighPriest.exe` VA `0x6F291C`. Read-only PE extraction identified the CP949 path `유저인터페이스\전장적표시.bmp`. OldRO `data.grf` contains it under `data\texture` as an indexed 24×24 bitmap with magenta transparency. The asset SHA-256 is `eb863352a1c28814e131d24e44d2c836fcdfa3c9daa0cf643b4c8f027afb39a6`.

The port projects current visible actors each frame in the shared world renderer. It queues the original bitmap without depth testing at the reference offsets, uses the full selected camp field, and applies the reference Gravity AID checks. Rendering follows the live actor list and camp state. This also lets an already-known enemy display once the local camp arrives, and removes the marker when camps become equal.
