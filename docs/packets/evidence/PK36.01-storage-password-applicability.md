- `023A` carries a 16-bit info value at offset 2. Values 0, 1, and 8 indicate unset, protected, and penalty states.
- `023B` carries a 16-bit change/check operation at offset 2 (2 or 3), with 16-byte fields at offsets 4 and 20. The field widths give no evidence of the transform used by a server that implements this feature.
- `023C` carries a 16-bit result and 16-bit error count. Values 4–8 cover change success/failure, check success/failure, and penalty.

The fixed frames use little-endian words. A protected challenge is `3a 02 01 00`. A check failure with two errors is `3c 02 07 00 02 00`. A layout-only `023B` check fixture has the prefix `3b 02 03 00` followed by 32 zero bytes. It exercises field boundaries without supplying a credential or describing a valid check request.
