# PK44.04 — Verify the optional 0x0200 login request gate

Date: 2026-11-04. Status: both opt-in and default-off ConnectAccount branches verified against a local mock.

## Source and client path

The selected server accepts fixed 26-byte `0x0200` (`u16 opcode` and `char name[24]`) as an ignored keepalive. The current client sends it from `CLoginMode::OnChangeState(LoginSubMode_ConnectAccount)` only when the `Login.SendConnectInfoChanged` INI value is nonzero; the setting defaults to false. That same state branch then selects a configured raw login request and sends `0x0064` in this fixture.

## Replay

The replay creates a temporary, isolated `open-midgard.ini` and uses a local listener as the account server. With the gate off, the captured stream contains only the 55-byte `0x0064` request. With the gate on, the captured stream is the 26-byte `0x0200` identity packet followed by the same 55-byte request. Both runs assert the production wait-for-response status. The temporary settings directory is removed after the replay; no real account credentials or remote server are used.
