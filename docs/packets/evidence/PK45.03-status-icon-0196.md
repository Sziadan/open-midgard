# PK45.03 — status icon packet 0x0196

Date: 2026-11-04. Status: fixed framing and handler dispatch effects traced; status-code semantics and selected-profile ownership remain open. No rows closed.

Opcode 0x0196 is registered at fixed size 9 and routed to `HandlePacket0196`. The handler requires data and at least nine bytes, reads status type u16@2, actor ID u32@4 and flag byte@8. It delegates to `ApplySelfStatusIconPacket` with active=`flag != 0`, remaining time 0 and the original flag.

The helper first calls `ApplyActorStatusVisual(mode, statusType, actorId, flag)`. It then updates the session's active status icon only when the nonzero actor ID matches either the session character GID or account AID; the stored icon receives the status type, active value and zero duration. The packet handler sends no reply.

Defer detailed visual/status-code effects to stronger review: `ApplyActorStatusVisual` owns a broader per-status actor presentation contract that is not established by this leaf. Also confirm the fixed size, field meanings, status flag polarity and actor-ID domain against the selected server/profile; replay unknown status types, zero actor IDs and local versus remote IDs.
