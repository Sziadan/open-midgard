# PK45.03 — warp skill destination list

Date: 2026-11-04. Status: client and selected-server fixed framing, list semantics, and UI transition traced; replay remains open. No rows closed.

Opcode 0x011C is registered to `HandleWarpMapList` and has a fixed 68-byte receive size. The handler requires non-null data, the expected opcode and at least 68 bytes. Under the registered fixed-size framing, the effective accepted packet is 68 bytes. It reads the skill ID u16@2, clears the prior destination list, then reads four fixed 16-byte map-name fields starting at offset 4. Each field is read up to its first NUL or the full 16 bytes; empty names are skipped.

If no nonempty destinations remain, the handler resets the warp skill ID to zero and closes the skill-selection window. Otherwise it opens/refreshes the warp destination window with the parsed list. No validation of map-name encoding or destination identity occurs here.
