# PK45.03 — making-arrow item list

Date: 2026-11-04. Status: variable framing, item extraction and skill-selection UI behavior traced; selected-server semantics and replay remain open. No rows closed.

Opcode 0x01AD is variable-length and routed to `HandleMakingArrowList`. The handler requires data, the expected opcode, at least the four-byte packet header and an even payload length. It reads each u16 item ID from offset 4 onward, skips zero IDs, and preserves the order and duplicates of nonzero IDs.

If a warp skill selection is active, the handler attempts `CancelWarpMapSelection()` before showing the arrow list. That helper sends a map-skill cancellation request; it clears the warp skill ID and destination list only if sending succeeds. The handler proceeds to open/reuse `UISkillSelectWnd` regardless of cancellation success, then replaces its content with the making-arrow entries. The window sets Arrow mode, title "Create Arrow", the empty-state text, and one icon/display-name entry per item ID (falling back to the numeric ID when no display name is available).

Open work: confirm header and item-ID semantics and duplicate/zero handling against the selected server/profile; inspect cancellation failure and window coexistence in replay; exercise empty, odd-tail and repeated-ID packets. No independent fixture or production replay was performed for this leaf.
