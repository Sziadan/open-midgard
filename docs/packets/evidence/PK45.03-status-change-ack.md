# PK45.03 — status change acknowledgement

Date: 2026-11-04. Status: fixed framing, accept/reject gate and session/player mutations traced; server result semantics and replay remain open. No rows closed.

The size table fixes 0x00BC at 6 bytes and the router maps it to `HandleStatusChangeAck`. The handler reads status type u16@2, success flag byte@4 (any nonzero is accepted), and value byte@5. A zero success flag returns without mutation or UI invalidation.

For status types 41–54 the helper updates the matching session combat field: attack/refine attack, MATK max/min, DEF/DEF bonus, MDEF/MDEF bonus, HIT, FLEE/FLEE bonus, CRITICAL, ASPD and plus ASPD. ASPD type 53 converts the raw motion value to display ASPD; plus ASPD type 54 is stored directly. This path invalidates status windows and returns.

Other types fall through to primary-attribute handling: types 13–18 write the value to selected-character STR/AGI/VIT/INT/DEX/LUK. It then synchronizes the local player's six primary stats from base plus session bonuses and invalidates status windows. Unknown types do not change an attribute but still run this sync/invalidation path.
