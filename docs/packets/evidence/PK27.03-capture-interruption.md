# PK27.03 capture interruption

The actor death and removal paths now retire a queued actor skill or touch action when the affected GID is its target. They clear both the player proceed and the mode chase state. An unsubmitted taming prompt for that GID closes, while a submitted prompt can still receive the targetless `01A0` result. A separately armed capture cursor remains available for a fresh click.

The existing `013B` rejection handling for types 0–2 now releases the held input and clears the player's queued skill along with the mode's retry state. This uses the normal button-release path. Informational type 3 leaves that state in place.

The production `0080` replay queues a capture, arms a separate manual intent, and stages a prompt for the disappearing actor. It checks immediate retirement, prompt closure and absence of a follow-up request. The `013B` replay stages held input and a queued capture and checks rejection, repeated delivery and informational results.
