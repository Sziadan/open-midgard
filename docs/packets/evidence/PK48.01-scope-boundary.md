# PK48.01 — certification scope boundary

PK48 is the independent certification review, not a self-certification pass. PK48.01 specifies inputs, review steps, evidence schema, and entry gates. It does not certify protocol parity and closes no coverage, finding, or ignored-registration rows.

Required inputs are the active plan and selected 20080910 rAthena source/config snapshot, runtime baseline, canonical contracts, ownership ledgers, package evidence, and independent byte fixtures. Ref is limited to original-client behavior. Each implementation claim must be tied to the actual registered opcode/guard/layout, parser and emitter branches, current-client path, independently sourced bytes, production replay, and the relevant lifecycle/UI behavior. A fresh deploy-off build and bounded error/malformed/lifecycle replays must be recorded with exact provenance.

These are explicit gates, not certification findings. PK48.01 makes no runtime changes and closes no rows. Resume implementation/evidence work before independent review.
