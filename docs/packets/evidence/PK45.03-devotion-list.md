# PK45.03 — devotion actor list 0x01CF

Date: 2026-11-04. Status: fixed framing and literal handler operations traced; selected server layout and route now traced; actor resolution and effect payload semantics require stronger review. No rows closed.

Opcode 0x01CF is registered at fixed size 28 and routed to `HandleDevotionList`. The handler returns unless data exists, length is at least 28, packet ID is 0x01CF, and `g_session.m_isEffectOn` is true. It reads devoter AID u32@2, resolves that actor through `ResolveSkillPacketActor`, and, if found, sends that actor message 109 with parameter 232 five times.

It then reads five devotee AIDs as u32 values at offsets 6, 10, 14, 18 and 22, skipping zero IDs. For every nonzero value it constructs `vector3d{float(devoterAid), float(devoteeAid), 0}`. If the devoter resolved, it launches effect 232 at a zero offset and sends effect message 14 with a pointer to that vector. The handler does not resolve each devotee actor, mutate logical devotion state, or send a network reply in this function.

Defer semantic interpretation to stronger review: the effect payload stores AIDs in vector coordinate fields, and both actor resolution and effect 232/message 14 contracts are external to this handler. Confirm the server's five-entry list layout, AID domain, effect gate and intended presentation against selected source/profile and replay. No independent fixture or production replay was performed.


## Selected server devotion-list layout (2026-11-04)

The pinned clif_devotion emitter writes a 28-byte 0x01CF frame: devoter AID u32@2, five devotee AID slots at bytes 6..25, and maximum-distance u16@26. For player devotion it fills the five slots from the player devotion array; the mercenary branch may place the master ID in the first slot. A non-null target session is sent SELF; otherwise the packet is broadcast to AREA. This confirms the S2C wire layout and recipient selection.

The current client converts the IDs into vector coordinates and dispatches effect 232/message 14. That adaptation is not established by the server wire contract and remains a stronger-review item; actor resolution and visible-effect behavior also need replay.
