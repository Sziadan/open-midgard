# PK45.03 — guild alliance, opposition and disband notifications

Date: 2026-11-04. Status: fixed variant framing, client messages, and pinned-server alliance/opposition/disband result codes traced; replay and lifecycle completeness remain open. No rows closed.

These branches share `HandleGuildNotification`:

- 0x0173 is fixed at 3 bytes. Result byte@2 maps values 0–5 to already allied, invitation declined, invitation accepted, other guild at alliance limit, local guild at alliance limit, and alliances disabled; other values produce a generic failure message.
- 0x0181 is fixed at 3 bytes. Result byte@2 maps values 0–3 to opposition registered, local guild at opposition limit, opposition already registered, and opposition disabled; other values produce a generic failure message.
- 0x015F is fixed at 42 bytes. It extracts fixed name[40]@2 and records “Guild disbanded: <name>” in system chat.
- 0x015E is fixed at 6 bytes and reads a u32 result@2. Zero reports successful disband and clears local guild, guild-window, guild-skill and guild-position state; it clears cached guild name/title on actor-name entries keyed by local GID or AID and sets the local player's guild ID/emblem version to zero when a player exists. Result 1 reports incorrect guild name; all other nonzero results report that members remain. Failure paths do not clear those states.

Any nonempty message is recorded in the system chat channel. Open work: confirm result code semantics and variant relationships against server emitters; verify that the 0x015E success cleanup is complete and 0x015F is only informational; replay each result, malformed/empty disband name and stale guild data. No independent fixture or production replay was performed for these branches.

## Selected server result-code follow-up (2026-11-04)

The hash-pinned server source documents alliance ack `0x0173` flags 0–5 as: already allied, request rejected, request accepted, other guild at alliance limit, own guild at alliance limit, and alliances disabled. The `0x0181` opposition ack flags 0–3 mean: antagonist set, antagonist limit reached, already an antagonist, and opposition disabled. The disband ack `0x015E` is a signed 32-bit reason: 0 success, 1 invalid key, and 2 guild still has members. The client strings/cases recorded above match these server meanings. Each ack is emitted to SELF. This confirms code labels and recipient scope from pinned source, but not every business-logic path that selects a code.

The client treats `0x015F` as a separate fixed-name informational notification; its server emitter/callsite and disband lifecycle ordering still need verification. Runtime replay and complete cleanup validation remain open. No discovery row is closed.
