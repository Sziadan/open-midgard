The production packet-stream replay exercises validation, type distinctions, detours, restoration, and map loading and replacement. The existing Ice Wall skill-unit lifecycle replay separately checks unit entry `011F`, loop effect 74, and removal `0120`.

The [native runner](../../../tools/tests/run_map_cell_preview.ps1) launches the rebuilt client in its opt-in Vulkan preview. It mounts the installed OldRO archives through a scratch directory, loads real Prontera RSW, GAT, and GND, picks the hover target through `CView`, and renders the actual `CView::OnRender` path. The blocked and restored runs route literal `0192` bytes through production framing and dispatch. The GAT base type remains 0 at cell (156, 184).
