Date: 2026-11-04. Status: selected-source result mapping, production framing and dispatch verified; visible modal remains unverified.

## Source trace and correction

The selected source's `chclif_createnewchar_refuse` sends a fixed three-byte `0x006E` packet. Internal `char_make_new_char` result -1 maps to wire 0 (name exists), -2 to 255 (creation denied), -3 to 1 (underage), and -4 to 3 (ineligible slot). The source explicitly leaves wire result 2 unused. No selected-source meaning was found for result 11.

The client previously described result 2 as a character-deletion restriction and result 11 as a premium requirement. Those meanings are not supported by the selected source. The handler now uses its numeric unrecognized-result fallback for 2 and 11, and explicitly maps result 255 to creation denied.

The replay sends emitted values 0, 1, 3 and 255, plus unassigned 2 and 11, through `CRagConnection::RecvPacket -> CLoginMode::PollNetwork -> OnRefuseMakeChar`. It asserts the exact status and return to CharSelect for all six three-byte fixtures. Records: `PK44.04-character-create-refusal.jsonl`.
