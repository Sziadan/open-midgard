# PK20.02 NPC class change implementation

The selected `HighPriest.exe` receiver at `0x5a6980` loads the GID at offset 2 and class at offset 7, then calls virtual slot `0x34` with the class and zero. The NPC constructor at `0x5d6ed0` installs vtable `0x6d745c`, whose slot points to `CNpc::SetSprAct` at `0x5d74d0`. This path invokes the job and sex setters without entering the spawn or state routines. The class-111 size multiplier in `CNpc::SetState` is therefore outside this packet path.

The production router resolves an existing non-player billboard carrier in the current world. On a class change it releases the old GR2 instance and owned billboard, drops borrowed resource references, and invalidates the world picking cache. The replacement keeps the actor, its motion, its map position and attached effects. Same-class packets leave the loaded representation intact. Missing actors, unresolved carriers and class values outside the runtime integer range are ignored.

`packet_npc_class_change_checks` frames literal packets through `TryReadPacket` and the default router. It checks actor identity and effect links, preservation of position and dimensions, texture ownership, picking-cache invalidation, sprite and GR2 job transitions, repeated class, class 111, a missing GID, truncated and out-of-range input, and a separate `01D7` hair update.

The deployment-disabled MinGW build passed all 166 application checks. All 473 standalone checks passed with the build's MinGW runtime on `PATH`. The plan validator passed. The installed OldRO executable hash stayed unchanged.

Rendered acceptance remains open. Run the selected assets through the native renderer and confirm that old GR2 bounds disappear immediately, new bounds become pickable after render, a failed or pending lookup cannot show the old appearance, and despawn and map teardown remove the last instance. Use the already staged GR2 assets under `build-mingw-preset/review-2026-11-05/gr2-corpse-native/stage` when available. The replay above changes GR2 class IDs without instantiating native models. The original setter also refreshes its per-job shadow factor from `CSession::InitShadowFactorWithJob`. The runtime currently uses a default actor shadow factor, so compare shadow scale during native parity review.
