# PK45.03 — guild relation add/remove

Date: 2026-11-04. Status: fixed add/remove branch framing and guild-window relation mutations traced; relation semantics and replay remain open. No rows closed.

Opcode 0x0184 is fixed at 10 bytes, routed to `HandleGuildWindowPacket`, then parsed by `ro::guild::ReadWindowPacket`. The parser requires at least 10 bytes, reads guild ID u32@2 and hostile flag u32@6 (nonzero means hostile), and erases every relation whose ID and hostile flag both match. A missing match is a successful parse with no mutation. The outer handler then recomputes the local member position/permissions/title when a matching local position exists; this branch does not add a relation or directly emit chat.

0x0185 is fixed at 34 bytes and shares `HandleGuildWindowPacket` and `ro::guild::ReadWindowPacket`. The parser requires 34 bytes, reads hostile u32@2 as a boolean, guild ID u32@6, and bounded name[24]@10, then inserts the relation or replaces the existing entry matching both ID and hostile flag. The outer handler applies the same local-position/permissions/title reconciliation as for 0x0184. Other opcodes sharing the guild-window parser have separate schemas and remain unverified.

Open work: confirm hostile encoding and add/remove semantics against the selected server; replay matching/absent relation IDs, hostile/nonhostile pairs, duplicate additions and removals; verify local-position/permission effects and guild UI refresh. No independent fixture or production replay was performed for this leaf.
