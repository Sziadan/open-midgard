# PK20.03 Native NPC class replacement

The [Vulkan fixture](../../../tools/tests/run_npc_class_change_preview.ps1) runs the built client with isolated assets and settings. It dispatches fixed `01B0` and `0080` records through the production framer and router, then uses the normal world renderer, picking cache and gameplay exit. The runner stages Poring, Ork Warrior, Archer Guardian, and Knight Guardian. It requires a fresh 640×480 capture and the individual checks from the fixture log.

- Poring becomes Ork Warrior with a different ACT and a new pickable billboard. Class 32767 has no sprite or pick target. Class 111 has a pickable hotspot and no billboard, and a repeat preserves its dimensions.
- Sprite to GR2 and GR2 to GR2 render and pick on the original actor. A repeated class retains its instance. Between the class change and the next render, the old GR2 bounds and pick target are gone. A second actor using the old model retains its instance.
- Switching to the unstaged treasure-box GR2 class leaves no model bounds or pick target after render. Switching back to the guardian and then to Poring rebuilds the appearance. The Poring ACT is still shared and usable.
- An `0080` removal drops the actor from picking immediately. Gameplay exit drains the deferred deletion and removes the remaining actor, their GR2 instances, and their world membership.

The original appearance setter clears the NPC body palette flag, and the selected `IsHaveAnotherPalette` returns false. The receive replay verifies the class, sex and palette update. The native shadow path uses the current NPC class. All 38 non-default non-player factors match the original `InitShadowFactorWithJob` bit-for-bit, including zero-scale suppression. The fixture does not measure the projected shadow at each non-default factor.

The fixture verifies the unresolved interval before the next render and a deterministic GR2 load failure. Its successful model swaps use staged assets whose CPU loads may already have finished. Live server verification remains in the broader packet plan.
