### Disconnect and return-to-character packet distinction

The source path confirms the `0x018B` refusal is valid for return-to-character, and also serves the quit-to-Windows request:

- Effective server registry: `src/map/clif_packetdb.hpp:61` registers `0x00B2` (3 bytes) with `clif_parse_Restart`; `:177-178` registers `0x018A` (4 bytes) with `clif_parse_QuitGame` and `0x018B` (4 bytes) as its reply.
- `src/map/clif.cpp:11837-11854`: `clif_parse_Restart` reads the request type. Type 1 checks logout restrictions; if blocked it calls `clif_disconnect_ack(sd, 1)`, otherwise it calls `chrif_charselectreq`. `clif_disconnect_ack` emits `0x018B` with a 16-bit result.
- `src/map/clif.cpp:11427-11462`: `clif_parse_QuitGame` also calls the same `0x018B` emitter with result 0 when disconnect is allowed and 1 when it is denied. Therefore `0x018B` cannot be interpreted as a return-to-character-only reply without considering the pending request.
- Ref has an explicit `HEADER_ZC_ACK_REQ_DISCONNECT` route (`Ref/dhxj/GameModePacket_2.cpp:912-914`) to `Zc_ack_req_disconnect` (`Ref/dhxj/GameModePacket.cpp:5746-5761`): result 0 disconnects and quits; result 1 displays the cannot-exit message. This is original-client behavior evidence, not proof of the rebuilt client route.
- The rebuilt client has `RequestReturnToCharSelect` sending `0x00B2` type 1 (`src/gamemode/GameMode.cpp:2296-2309`) and separately `RequestExitToWindows` sending `0x018A` (`:2323-2331`). Current framing has a 3-byte `0x00B3` size but no `0x018B` entry (`src/network/GronPacket.cpp:93-100`); the router registers `0x00B3` only (`src/gamemode/GameModePacket.cpp:8744-8747`). `HandleDisconnectCharacterAck` consumes `0x00B3`, clears its pending action and transitions (`:7855-7875`); there is no corresponding rebuilt-client `0x018B` handler.

The `0x018B` result meaning depends on request context, and pending-action/Session/Qt behavior across success, refusal, cancellation and connection teardown still needs an independently approved contract and production-path replay.
