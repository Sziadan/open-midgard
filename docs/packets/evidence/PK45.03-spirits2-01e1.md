# PK45.03 — spirit effect packet 0x01E1

Date: 2026-11-04. Status: fixed framing and literal actor/effect operations traced; job mapping and effect contracts need stronger review. No rows closed.

Opcode 0x01E1 is registered at fixed size 8 and routed to `HandleSpirits2`. The handler requires data, at least eight bytes, matching packet ID and `g_session.m_isEffectOn`. It reads actor AID u32@2, resolves through `ResolveSkillPacketActor`, and returns if unresolved. Job 4038 selects effect 504, job 24 selects 629, and all other jobs select 228.

It checks the actor's current effect state for burrow or hiding. If hidden, it sends actor message 109 with the effect ID and returns. Otherwise, only when that effect does not already exist and AID is nonzero, it launches the effect at zero offset and, if successful, sends effect message 14 with a vector whose X is signed i16@6 converted to float (Y/Z stay zero). Unlike 0x01D0, this handler does not send message 109 before the hidden check and suppresses duplicate existing effects. No network reply or logical spirit counter update occurs here.
