# PK45.03 — pet status

Date: 2026-11-04. Status: fixed framing and parser/session mutation traced; selected-server signedness and replay remain open. No rows closed.

The size table fixes 0x01A2 (`ZC_PROPERTY_PET`, annotated for 20080910) at 35 bytes and the router maps it to `HandlePetStatus`. The handler delegates directly to `ro::pet::ReadStatus` with the session pet-status record and packet view.

`ReadStatus` accepts only non-null data of exactly 35 bytes with packet ID bytes `A2 01`. It decodes a NUL-bounded name from bytes 2–25 (maximum 24), signed modified byte@26, signed 16-bit level@27, fullness@29, relationship@31 and accessory item ID@33. It constructs a temporary `Status`, marks it valid, and replaces the session record only after all fields are read. The handler ignores the parser's boolean result, so invalid input leaves the prior status unchanged without logging or UI refresh.
