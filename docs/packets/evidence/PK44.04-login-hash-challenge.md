# PK44.04 — Replay 0x01DC challenge and 0x01DD login request

Date: 2026-11-04. Status: bounded production-helper replay verified; end-to-end profile reachability remains unresolved.

## Source trace

The selected server source emits `0x01DC` as a variable packet with a four-byte header and `md5keylen` salt bytes. `logclif_parse_reqkey` sets `md5keylen` to the 20-byte `login_session_data::md5key` capacity; `logclif_reqkey_result` sets `packetLength = sizeof(header)+md5keylen` and copies the salt. The selected server frame is therefore 24 bytes.

The current client's `SendPasswordHashRequest` sends the two-byte `0x01DB` request. The replay captures those bytes from the production helper, then feeds a deterministic 24-byte `0x01DC` challenge to `OnAckHash`, which builds the selected profile's 47-byte `0x01DD` request. Its `g_passwordEncrypt2` branches match the Ref `Ac_Ack_Hash` order: mode 0 hashes `salt + password`; mode 1 hashes `password + salt`. `ShouldRequestPasswordHashOnConnect` gates the production sender using `passwordencrypt` unless `ForcePasswordHashRequest` overrides it. `g_passwordEncrypt2` is set from a per-client `clientinfo.xml` `<passwordencrypt2>` option, rather than from packetver. No applicable clientinfo XML is present in this checkout, and a Ref `0x01DB` request send site was not found. Thus the sender helper bytes and both challenge digest branches are checked, but intended real-client configuration and negotiation reachability remain unknown.

## Production-helper replay

The replay invokes production `SendPasswordHashRequest` and captures `db01` through a local peer. It then feeds a synthetic 24-byte `0x01DC` frame (`20` salt bytes `0x20` through `0x33`) to the same `CLoginMode::OnAckHash` handler used by LoginMode. For each setting it captures the actual 47-byte request through a local peer, checks opcode `0x01DD`, selected client date `20080910`, synthetic account ID, and the expected MD5 bytes:

- `salt + password`: `e30bf739e82f48e80e85d68a47981cad`
- `password + salt`: `54ad6400ff9529c355b65b9afb05f42d`

The captured `0x01DB` request, full `0x01DD` requests and input challenge are recorded in `PK44.04-login-hash-challenge.jsonl`. This does not exercise the configuration gate that decides whether to request a challenge, actual server salt generation, clientinfo profile selection, credential validation, or the LoginMode UI/modal path.
