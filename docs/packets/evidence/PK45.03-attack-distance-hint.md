# PK45.03 — attack failure distance hint

Date: 2026-11-04. Status: packet framing and hint-state mutation traced; downstream chase behavior and trigger-caller reachability remain open. No rows closed.

The receive router maps 0x0139 to `HandleAttackFailureForDistance`; the size table fixes it at 16 bytes. The handler reads target GID u32@2; signed 16-bit target X/Y@6/@8; signed 16-bit source X/Y@10/@12; and attack range u16@14, clamped to at least one. It records the current tick, all decoded values, and sets `m_hasAttackChaseHint`.

The packet handler does not itself move the actor or send a request. `GameMode.cpp` later consumes the target-keyed hint in attack-chase logic; that consumer also consults current movement destination and source/target tile resolution. A complete behavioral contract needs to trace that state machine and its clearing paths together with the server's intended retry/range semantics.

Open work: verify signedness and range units across the effective server variant; trace hint expiration/clearing and retry behavior in the full chase consumer; replay success/failure, stale target, map transition, and repeated hints.
