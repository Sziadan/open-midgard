# PK45.03 — viewed-player equipment list

Date: 2026-11-04. Status: client receiver/UI data path and selected server header/row semantics are source-traced. Visible window acceptance and replay remain open. No rows closed.

Opcode 0x02D7 is variable length. The commerce receiver requires at least 43 bytes and an exact multiple of 26 bytes after that header. It parses each row with the equipment-item layout used by the cart equipment lists (including the four-byte delete-time field); the shared conversion reads through row byte 23 and leaves the final two bytes of each 26-byte row unused. It replaces `state.viewedEquipment` with the parsed vector, shows the equipment window, reads the displayed player name from byte 4 for up to 24 bytes, and sets the status to “Equipment shared by this player.” Unlike cart-list parsing, this branch does not filter rows with zero item index, item ID, or amount.

The selected server source confirms the 43-byte header and 26-byte equipment rows described below, matching the client framing and row parser. Empty/single/multiple-row fixtures, all row attributes, and visible window acceptance still need production replay; no discovery rows are closed.
