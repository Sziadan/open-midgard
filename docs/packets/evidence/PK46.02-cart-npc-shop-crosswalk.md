# PK46.02 selected cart and NPC shop requests

Lengths and registration fields come from the pinned MAIN 20080910 registry. Parser descriptions refer to the inspected local `clif.cpp` (SHA-256 `76c1c4202040daab90f2e441ffad05d9b9ce612d2a16edba55d2926c83ccbb6e`), which differs from the PK01.02 pin.

## PK46.02-CART-REQUESTS

- `0126` and `0127` are eight-byte inventory-to-cart and cart-to-inventory requests. The commerce transfer action sends a two-byte wire index at offset 2 and a four-byte quantity at offset 4. The server converts the wire index and checks cart availability and action restrictions before dispatch. Loopback replay checks both directions, excessive quantity rejection, and preservation of local counts pending server updates.
- `012A` is a two-byte remove-option request. The cart-off action uses that opcode. The server clears riding, falcon, dragon, or Mado before removing a cart when one of those options is present. The client labels its action Cart Off. Replay verifies the opcode, and live option priority and resulting state remain open.
- `01AF` sends the two-byte cart appearance type at offset 2. Replay checks client types 1–5 and rejects out-of-range input. The selected server checks the Change Cart skill and the level threshold for the type.

The server also registers eight-byte `0128` and `0129` requests for storage-to-cart and cart-to-storage. Their parsers use different index conversions and select personal, guild, or premium storage from the open server context. The client transfer action covers inventory and cart. Storage-to-cart and cart-to-storage remain open for PK37 UI and lifecycle work.

## PK46.02-NPC-SHOP-REQUESTS

- `00C5` is seven bytes. The selected NPC GID is at offset 2 and the buy/sell choice is at offset 6. Production replay starts at the mode action and verifies the choice and matching quote family.
- `00C8` and `00C9` are variable-length requests with a two-byte length at offset 2 and four-byte rows starting at offset 4. Buy rows carry quantity followed by item ID. Sell rows carry inventory index followed by quantity. The parser requires a shop context and clears it after handling the list. Replay captures both frames and verifies that a result for the other family leaves the submitted request pending.

Live transfers, cart option results, NPC shop results, and PK48 independent review remain open.
