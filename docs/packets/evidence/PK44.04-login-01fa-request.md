# PK44.04 — Add explicit 0x01FA login3 request path

Date: 2026-11-04. Status: selected-source request identity and bounded current-client sender verified; deployed profile intent and PC-bang `clientinfo` variant remain open.

## Source contract

The selected server's `PACKET_CA_LOGIN3` is packed to 48 bytes: opcode `0x01FA`, version, username[24], password MD5[16], client type, and `clientinfo` at byte 47. `loginclif.cpp` registers the fixed-size parser without a `PACKETVER` guard. `logclif_parse_reqauth_md5<PACKET_CA_LOGIN3>` consumes the same username, client type, and password-MD5 fields as `0x01DD`; this source parser does not read `clientinfo`. Source hashes: `src/common/packets.hpp` `07B47B66A41ED05433F852E399BA1D714BA728074F76633AD77BC2F7720D79EF`; `src/login/loginclif.cpp` `A0EEA56F5A41286674AE27CAAD5B57E192B298E20C0FDDC38F015B0C2ECE5E3F`.

Ref's `Ac_Ack_Hash` builds `0x01FA` for its Thai service branch and copies `m_SelectAccountNumber` to `clientinfo`; the PC-bang subcase adds 10. The current client has no corresponding PC-bang state in this login3 path, so this implementation uses the selected client-info index and does not claim the `+10` variant. Ref source hash: `Ref/dhxj/LoginMode.cpp` `91C3F4E873ECD9C69DBCE8DF62761699BFA79684E9FFA3F42F732D8376B6D75B`.

## Change and production replay

`AccountLoginPacket=login3` now selects an explicit login3 profile. It automatically sends `0x01DB`, waits for the production-framed `0x01DC` challenge, and responds with the 48-byte `0x01FA` packet. The selected client-info index must fit in the one-byte field; invalid values reset the account handshake, disconnect, and return to Login with an error status. Other login modes keep their prior packet behavior.

The replay creates an isolated two-entry clientinfo fixture, selects index 1, connects through the production ConnectAccount path to a local mock account server, captures `db01`, sends the selected-source 24-byte challenge, then captures and compares the complete response against independent byte literals. The expected MD5 `e30bf739e82f48e80e85d68a47981cad` is an independent salt+password vector. The exact frame is recorded in `PK44.04-login-01fa-request.jsonl`.
