## User action to sender

`UIShortCutWnd` changes or clears shortcut slots in local session state before sending `GameMsg_RequestShortcutUpdate` for each affected absolute slot. `UIWindowMgr` also clears a dragged shortcut when it is dropped outside the shortcut window and requests an update. `GameMode` dispatches to `RequestShortcutSlotUpdate`, which rejects an absolute index with no local slot, reads the current slot state and sends it. The local slot mutation is not rolled back if sending fails.

## Client layout and profile

`PACKET_CZ_SHORTCUT_KEY_CHANGE` is sent with `LegacyShortcutSend::kKeyChange` (`0x02BA`): opcode at offset 0 (2 bytes), absolute index at offset 2 (2 bytes), item/skill flag at offset 4 (1 byte), item or skill ID at offset 5 (4 bytes), and count/skill level at offset 9 (2 bytes), for 11 bytes total. Empty slots serialize `IsSkill=0` while preserving the slot's serialized ID/count values.
