Date: 2026-11-04. Status: configured current-client sender branch verified with a local capture; deployed profile applicability remains open.

## Source contract

The selected rAthena login parser registers fixed 84-byte `0x0277` and routes it through the generic raw-password parser. Its packed layout is opcode@0, client date@2, username[24]@6, password[24]@30, client type@54, IP[16]@55, and MAC[13]@71. The current client selects `SendLoginPcBang` when `Login.AccountLoginPacket=pcbang`; it writes local IP and the fixed `111111111111` MAC string.

## Replay

The local mock captures an 84-byte `0x0277`. The fixture checks fixed offsets, version, padded credentials, client type, OS-resolved IPv4 and the MAC string/termination. No live server or credentials are used.

This confirms the configured sender implementation only. Ref has no verified active `0x0277` send site in the reviewed path, and the deployed service's intended profile is unknown. The packet remains open in discovery; deployed-profile reachability and auxiliary IP/MAC semantics are not claimed.
