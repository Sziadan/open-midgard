# PK25.03 Compass and map restriction notices

The selected local `20080910` server sends `0144` as a 23-byte frame. The original client ignores the NPC ID at offset 2. Type, X, Y, marker ID and color start at offsets 6, 10, 14, 18 and 19. The receiver replaces the ID's coordinates, color, type and start time on update. Type 2 removes the ID. Type 0 expires after 15 seconds and other stored types remain until cleared. Local death removes persistent markers, and teleport, map transition and mode teardown clear the map's markers. [Selected source scope](PK25.01-dialogue-script-scope.md)

Both minimaps use the existing map-cell projection and render the original cross shape, lit during the first 500 ms of each second. Native redraw uses the currently visible marker set in its cache token. The Qt marker model carries the same packed RGB, position and shape. Out-of-map points are excluded.

The production replay checks `0144` framing, field offsets, replacement, expiry, blink, explicit removal and malformed frames. The map and death replay covers persistent marker removal on local death and clearing during same-map warp. Native and Qt minimap captures verify cross pixels, blink phases and removal. Captures are under `build-mingw-preset/packet-minimap-renders`.

The existing `0189` receiver uses the original packed RGB colors, red for type 0 and cyan for types 1–3. Production replay checks the four texts, the item-acknowledgement reset for type 3 and the unknown-type no-op. [Dual-history verification](PK25.04-verification-boundary.md)
