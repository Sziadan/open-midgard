# PK42.02 instance state

The production router frames and dispatches the four [selected instance replies](PK42.01-selected-instance-contract.md). A named reservation replaces the snapshot, and a named status installs the two unsigned deadlines. Queue cancellation and terminal status clear the current snapshot. Known terminal results display the original localized notices, with create failure closing silently. Unknown status types leave the snapshot intact. An unnamed deadline update cannot bootstrap an instance.

The snapshot belongs to the character session so an ordinary map change can rebuild the world without losing the reservation. A server move clears the previous snapshot before reconnect, and leaving gameplay clears it on mode exit. PK42.03 owns the window, countdown presentation, and the selected command and confirmation paths.

The deploy-off MinGW build passed the full packet stream replay, chat notice replay and world-entry handoff checks. Replay covers concatenated selected frames, a fully occupied 61-byte name, both unsigned deadlines, timer stop and restart, negative queue cancellation, known terminal types, unknown types and a notification without a prior snapshot. The map transition fixture checks preservation on `0091` and clearing before both successful and failed `0092` reconnects.
