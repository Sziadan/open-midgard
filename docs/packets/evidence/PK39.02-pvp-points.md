# PK39.02 PvP points

The existing source chat submission handles `/pvpinfo` in case 141. It writes `020F`, the session AID, and the session GID in ten bytes when the world is flagged as a PK zone. The selected rAthena parser `clif_parse_PVPInfo` answers for the sender and leaves the supplied identifiers unused. The slash-command replay verifies both IDs and confirms the command is quiet outside a PK zone.

The selected `clif_PVPInfo` reply is 22 bytes. It carries character ID and account ID, then wins, losses, and points. `Ref/GameModePacket.cpp::Zc_Ack_PvpPoint` displays the last three fields as signed decimals in message 853 (`MSI_PVP_INFO`) and expands chat before sending cyan system text. The receiver uses the existing localized formatter with English fallback for missing or invalid templates. The production stream replay verifies field order, negative points, cyan output, and framing through the next broadcast.

Live PvP points and the separate `019A` rank display remain open.
