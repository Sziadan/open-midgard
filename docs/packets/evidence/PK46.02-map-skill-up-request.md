# PK46.02 — skill-level upgrade request

Date: 2026-11-05. Status: current UI actions, client layout and selected parser traced; client skill-list refresh parsing is now documented without assuming it follows this request. Upgrade result lifecycle/replay remains open. No discovery row is closed.

The classic skill list sends `GameMsg_RequestUpgradeSkillLevel` when the clicked skill is marked upgradable and the player has a skill point. The Qt skill-tree apply path sends the same message for each next draft upgrade accepted by its apply model. `RequestUpgradeSkillLevel` rejects skill ID zero, serializes `PACKET_CZ_SKILLUP`, and sets the pending-upgrade flag after a successful send.

All configured map gameplay profiles select opcode `0x0112`. The packet is four bytes: opcode u16@0 and skill ID u16@2. The selected 20080910 registry records `0x0112`, length 4, `clif_parse_SkillUp`, with the skill ID at offset 2. The parser reads that registered u16 and passes it to `pc_skillup`.

This confirms the common wire identity and current UI entry points. Server authorization/point consumption, failure/result packets, retry ordering for the Qt apply queue, and the visible skill-tree refresh were not replayed or independently byte-checked. No discovery row is closed.

## Client skill-list receive path follow-up

The client fixes `0x010F` as variable-length and routes it to `HandlePlayerSkillList` (`src/network/GronPacket.cpp:181`, `src/gamemode/GameModePacket.cpp:8849`). The handler validates that the payload after the four-byte header is divisible into 37-byte entries, clears the selected player skill cache, filters entries to the player-skill ID range, and rebuilds the session skill list (`GameModePacket.cpp:1956-2035,2070-2073`). This documents how a full skill-list update refreshes client skill levels/upgradable flags; available source evidence does not establish that it is the response to `0x0112`.

Replay the selected server response sequence and Qt apply-queue behavior before linking this refresh to an upgrade or closing the row.
