# PK04.02 — Character-server raw-prefix receive state

Date: 2026-11-04. Status: implementation checkpoint; PK04.03 production behavior replay is still required before the handshake is considered verified.

## Change

`CRagConnection` now has an opt-in `ExpectRawAccountIdEcho(u32)` receive policy. The ConnectChar path arms it after a successful new char-server connection and before sending `0x0065`. While armed, production `RecvPacket` waits for four bytes, consumes and compares the full little-endian value, and only then resumes opcode framing on the remaining queue. A mismatch closes the socket and drops buffered trailing bytes. `CConnection::Connect` and `Disconnect` now invoke the existing virtual lifecycle hooks; the Ragnarok implementation resets the expectation on connect/close, preventing carryover through EOF, failure, explicit disconnect, or reconnect. Non-character connections are never armed by production call sites. Removed fake size registrations and silent `PollNetwork` cases for `0x8482`/`0x8483`.

## Scope and self-review

Changed only `Connection.h/.cpp`, `GronPacket.cpp`, and the ConnectChar/request receive path in `LoginMode.cpp`. Account-server and map-server callers retain their existing framing. The active raw expectation is placed ahead of the generic packet decoder, so a low-word collision cannot reach a handler before all four bytes have arrived and matched. A mismatch clears connection queues through `Disconnect`; `OnUpdate`'s existing closed-connection path returns to Login. EOF with a partial prefix also closes and clears through the existing receive error path; its exact transition still needs PK04.03 replay.

PK03.02 dependency evidence covers the exact production receive queue's fragment/coalesce/EOF/reconnect mechanics. PK03.03/03.04 remain blocked at Session/UI/full-frame boundaries, which this raw connection-layer API does not use. This is narrow dependency evidence, not a claim that PK03 is package-complete. Discovery parents AUDIT-0x8482 and AUDIT-0x8483 remain unresolved until PK04.03.
