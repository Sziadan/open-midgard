# PK45.03 — skill unit disappearance

Date: 2026-11-04. Status: framing and world ownership mutation traced; server identity semantics and replay remain open. No rows closed.

The receive size table fixes 0x0120 at 6 bytes and the router maps it to `HandleSkillDisappear`. The handler requires a data pointer, at least six bytes, and a live world, then reads a u32 unit ID at offset 2 and calls `CWorld::RemoveSkill`.

`RemoveSkill` searches the world skill list by `m_aid`, removes the matching pointer from that list and the game-object list, then deletes the skill object. A missing ID returns false and has no additional handler-side effect or log. The handler ignores the return value.
