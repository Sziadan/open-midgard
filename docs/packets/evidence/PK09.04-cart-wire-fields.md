# PK09.04 — selected cart wear/bind field repair

Verified 2026-11-05. This is a bounded source/field repair within PK09.04 self-review, not whole PK09 completion or UI acceptance.

The selected server's `EQUIPITEM_INFO` defines WearState u16@8 and bindOnEquipType u16@24, in a 26-byte record. `clif_item_equip` writes both fields. The inventory decoder already retains them, but Commerce's shared equipment-item decoder discarded both. It now stores WearState in `m_wearLocation` and the raw bind word in the existing legacy `m_isYours` member when the entry has at least 26 bytes. The legacy member name does not make this a boolean ownership claim: selected bind values 0/1/2 remain raw values. Historical shorter records keep their existing behavior. No guessed cart-ammunition normalization was added from inventory behavior alone.

The [independent guarded-header probe](PK09.04-cart-fields-probe.cpp), compiled against the selected server wrapper, statically asserts PACKETVER=20080910, normal/equipment sizes 22/26, and wear/expiry/bind offsets 8/20/24. [Probe output](PK09.04-cart-fields-probe.txt) records the result. This establishes selected layout independently of client decoders.

The Luna-drafted, primary-reviewed `CartItemWireFieldsReplay.inc` supplies independent literal 0x02D2 and 0x02E9 bytes to the actual CRagConnection queued receive extraction, packet framing, production router and Commerce handler. It checks index/ID/type/identified/count/location, nonzero wear state, damage/refine, all four cards, 32-bit expiry and bind word 2. It also checks normal-card/expiry fields, malformed equipment-list preservation of prior values, and empty equipment-list clearing while normal cart items survive. It imports no client packet serializer. Fixtures prove decoder behavior, not a captured/live transaction or the reachability of every synthetic field combination.

Both deploy-off app/replay targets built. Authorized loopback CTest passed **1/1 in 4.88 seconds**, with **159 PASS JSON records**. [Input/server/binary provenance](PK09.04-cart-wire-fields.json) and [replay records](PK09.04-cart-wire-fields.jsonl) pin the result. Three runtime/test inputs comprise this repair; broader PK09.04 source/variant/UI/lifecycle acceptance remains IN_PROGRESS. Active priority remains PK14.04.
