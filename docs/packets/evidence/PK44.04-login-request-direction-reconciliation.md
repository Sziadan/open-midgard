Date: 2026-11-04. Five login request discovery parents now have evidence-backed `C2S_ONLY` direction classifications.

## Basis

The pinned rAthena login packet database registers the corresponding fixed-size parsers as client-to-server requests. PK44.04 production captures independently verify that the current client sends each request:

- `AUDIT-0x01DB`: the forced `ForcePasswordHashRequest=1` ConnectAccount branch emits the exact two-byte request and enters the hash-challenge wait status. Evidence: `PK44.04-password-hash-request-gate.md` and `.jsonl`.
- `AUDIT-0x0204`: the gated executable-hash branch emits the exact 18-byte request with a synthetic MD5 override; a second isolated fixture verifies relative executable-file resolution against the known MD5 of `abc`. Evidence: `PK44.04-executable-hash-gate.md`, `PK44.04-executable-hash-source-file.md`, and their JSONL records.
- `AUDIT-0x0277`: explicit `AccountLoginPacket=pcbang` selection emits the selected-source 84-byte request, matching the independent field fixture. Evidence: `PK44.04-pcbang-login-request.md` and `.jsonl`.
- `AUDIT-0x02B0`: explicit `AccountLoginPacket=channel` selection emits the selected-source 85-byte request, matching the independent field fixture. Evidence: `PK44.04-channel-login-request.md` and `.jsonl`.
- `AUDIT-0x01FA`: explicit `AccountLoginPacket=login3` automatically requests `0x01DB`, routes the selected-source 24-byte `0x01DC` challenge, and captures the exact 48-byte `0x01FA` request with independent digest and selected client-info index. Evidence: `PK44.04-login-01fa-request.md` and `.jsonl`.

The current-client production send paths establish C2S direction under the stated gates/configurations, consistent with the existing `C2S_ONLY` classifications for `0x0064` and `0x0200`. This does not establish which service profile is intended for deployment, prove live server compatibility, or close semantic/login-state coverage. No response identity is inferred from these requests. `0x01DD` and `0x027C` remain direction-classified but retain separate deployed-profile/reachability questions; `0x0825` remains unreviewed for its security-sensitive dynamic length/token path.
