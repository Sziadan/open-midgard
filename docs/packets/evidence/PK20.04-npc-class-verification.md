The selected `packetver23` client and local rAthena `20080910` sender agree on fixed 11-byte `01B0` framing, GID and class offsets. The original executable ignores the type byte and calls the existing NPC's class setter. The selected emitter targets NPCs, monsters and homunculi. The receiver applies only to an existing non-player actor in the current world. The original class setter's sex and palette reset is covered by the production replay. The `01D7` look packet retains its own handler. [Source scope](PK20.01-npc-class-replacement-scope.md) · [Production replay](PK20.02-npc-class-change.md)

The native run verified visible sprite replacement, an invisible class, a hidden hotspot, restored appearance, a failed GR2 load, same-class preservation, picking, and cleanup. The old GR2 instance is erased before setting the new class. `GetAsset` returns no asset while its future is pending, and `RenderGr2Monster` creates bounds only after a successful asset lookup. The fixture verified absent bounds before rendering and after a deterministic load failure. It did not force the worker future to remain pending. `0080` unregisters the actor immediately, and the normal update loop and gameplay exit both drain deferred actor deletion.
