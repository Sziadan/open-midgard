# PK45.03 — ground-skill notification 0x0117

Date: 2026-11-04. Status: server layout/routing and client actor/effect path traced; skill-specific visual parity and replay remain open. No rows closed.

The selected server defines `0x0117` as an 18-byte `ZC_NOTIFY_GROUNDSKILL`: skill ID u16, source actor ID u32, level/x/y u16, and client tick u32. `clif_skill_poseffect` fills these fields. Normal sources broadcast AREA; disguised sources use AREA_WOS and then a SELF copy with disguised actor ID.

The client size table fixes `0x0117` at 18 bytes. `HandleGroundSkillNotify` checks the active profile ID and world, decodes the same offsets, resolves the source actor, sends actor message 38 with skill/cell/time arguments, and sends world message 99 for non-monster sources. It has additional local behavior for skill IDs 47, 362, and 369.
