# PK09.07 — source-defined ordinary item name contexts

2026-11-05. Dedicated commit subject: `packet(PK09.07): distinguish hover and list item names`.

Primary source review found two concrete differences: ordinary inventory hovers inherited computed socket suffixes from list-label metadata handling, and Qt commerce row names called the refinement/card builder unconditionally even for unidentified items. The actual rendered QML regression first failed with `actual item hover incorrectly appended a list-only socket count`.

[Contract](../contracts/PK09.ITEM-NAME-CONTEXT.md) records the source branches. `ITEM_INFO`/`CItemMgr` now allow explicit omission of the socket suffix. Shared item hovers request plain metadata names with source-defined refinement/identification rules; existing list labels retain their socket suffix. Qt rows call the same identification/type-aware helper. Primary type 19 is included in that helper's composition set.

The real render harness dispatches independent literal 20080910 equipment snapshots with refine seven in identified and unidentified variants, checks native hover data and both Qt inventory/cart row names, then inspects the actual QML hover label and saves four frames. Earlier six colour cases now also assert exact hover names. Normal inventory/cart snapshots replace quantity nine with one; actual QML stack-label text and inherited visibility, native counts and three retained quantity/empty frames are checked. Empty snapshots remove real delegates and an active hover. The test uses the existing source-extracted Knife/Dagger/slot metadata and declared transparent icon/chrome assets; amount tests use literal normal-arrow rows, without asserting absent metadata/art.

Primary Ref and external source remain read only. No installed client or live server is used. Current verification results, source/reference/binary hashes, failure record and retained frames are recorded in [provenance](PK09.07-item-names.json).

Remaining strong-agent work: primary card prefix/postfix algorithms group card IDs, whereas current code groups prefix strings and does not aggregate postfixes; manufactured/named-pet sentinel behavior also remains open. It formats the raw Unix expiry using localtime and localized TIME_TYPE2/NOTICE_TO_DELETE_TIME; source-extracted English GRF rows are `%m/%d %H:%M` and ` ^ff0000Expiration Date: %s^000000`. Trace the detailed-window mapping, add an absolute-date row with real native/Qt checks, then verify selected `0299` expiry removal. Never reuse timed-status countdown fields or add invented countdown hover text. Broader PK09.04 and independent PK48/49/deployed provenance remain open.
