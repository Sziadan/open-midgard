# PK45.03 — local guild membership update

Date: 2026-11-04. Status: fixed framing and local/session/actor mutations traced; selected-server field semantics and replay remain open. No rows closed.

The size table fixes 0x016C (`ZC_UPDATE_GDID`) at 43 bytes and the router maps it to `HandleGuildBelong`. The handler requires at least 43 bytes and reads guild ID u32@2, emblem version u32@6, permissions u32@10, master flag byte@14, and guild name[24]@19. Bytes 15–18 and the rest of the packet are not consumed by this handler.

It updates `g_session.m_localGuild`. If the stored character ID differs from the current GID or the guild ID changes, it first zeroes the local guild record and guild window and clears guild skill items. It then stores current character/guild IDs, emblem version, name, permissions and master flag. If there is no world/player, it returns after updating session data. Otherwise it also sets the player guild ID and emblem version and updates the local player's guild name in `m_actorNameListByGID`.

Open work: validate the offsets and meaning of unused bytes against the selected server source; inspect reset behavior when the packet reports guild ID zero; confirm window/cache/UI refresh expectations; replay same-guild updates, guild changes, character changes, no-world receipt and leave-guild transition. No independent fixture or production replay was performed for this leaf.
