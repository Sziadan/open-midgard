## Selected server identity for ignored 0x01B0 (2026-11-04)

The selected server names fixed `0x01B0` as `ZC_NPCSPRITE_CHANGE`, with actor ID u32, type byte, and class/sprite ID u32 (11 bytes total). `clif_class_change` returns early when the requested class is a player class, otherwise writes the block ID, sets the type byte to zero (commented unused), fills the requested class ID, and sends using the caller-provided target scope.

The client correctly frames and dispatches this packet but its handler is empty, so NPC sprite/class changes are not applied through this path. Whether this is intentional for the selected client/profile or a visible parity gap requires runtime replay. No discovery row is closed.
