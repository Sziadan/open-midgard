# PK44.04 — Replay 0x0069 login acceptance

Date: 2026-11-04. Status: bounded production framing, routing and handler replay verified; socket connect and visible UI remain open.

## Fixture and production entry

The fixture is an independent 79-byte selected-source frame: a 47-byte `AC_ACCEPT_LOGIN` prefix and one 32-byte character-server record. It carries synthetic auth/AID/login-id2 values, regional sex value 11, server address bytes `c0 a8 01 0a`, port 6121, name `char-main`, user count 3, type `0x1234`, and new flag 2. Expected values are written as byte literals in the replay rather than generated from the client packet struct.

The replay sends the frame through `CRagConnection::RecvPacket -> CLoginMode::PollNetwork -> OnAcceptLogin` and checks the parsed session fields, sex normalization to 1, all server-record values, automatic selection of the single server, transition to `LoginSubMode_ConnectChar`, acceptance status, and reset of the account-login handshake fields. The result is recorded in `PK44.04-login-accept-reply.jsonl`.
