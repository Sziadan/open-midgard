# PK22.01 — ShowEFST and extended status scope

## 0x028A contract

- The selected frame is 18 bytes, with GID u32 at 2, OPTION u32 at 6, signed level i32 at 10, and OPT3 u32 at 14. The current handler implements the level-99 aura except under special hiding, and PC Assumptio for OPT3 bit 0x800.
- Ref/GameModePacket.cpp `GameModeShowEFST` is the 2008 reference branch. It includes level-99/special-hiding handling; PC vs non-PC; hidden/burrowed cleanup of effects 203, 254, 418, 586; showEFST visual branches using masks 0x1, 0x2, 0x4, 0x4000, 0x8, 0x10, 0x1000, 0x2000, 0x8000, 0x20000, 0x10000, 0x40, 0x100, 0x80, 0x200, 0x400, and 0x800; and bit 0x20 movement-freeze/gray-ARGB behavior with job-specific animation cases. Some branches are priority-ordered and others independent.
- The selected local rAthena `20080910` sender is `src/map/clif.cpp::clif_changeoption2` with the packed layout in `src/map/packets.hpp:1097–1104`. It sends normal updates to AREA. For a disguise it sends the original GID to AREA_WOS, then the disguised GID to SELF, then the original GID and `OPTION_INVISIBLE` to SELF. The selected status-end path invokes it for `SCF_NONPLAYER` in `src/map/status.cpp:14089`.
- `Ref/GameModePacket.cpp::GameModeShowEFST` checks the incoming OPTION's special-hiding bit for the level-99 aura, then reads the actor's existing OPTION for concealment branches. OPT3 carries a separate bit namespace. The normal and disguised IDs are still resolved through the existing actor lifecycle.
- PK22.02 owns branch parity and actor flag lifetime; PK22.04 owns per-status start/refresh/end and teardown behavior.

## 0x043F boundary

- Current 0x043F is fixed at 25 bytes. The handler reads status (u16 at +2), actor ID (u32 +4), flag (+8), and remaining time (u32 +9), then ignores remaining bytes +13..+24.
- The selected server uses the untimed `0196` path. See the completed [PK22.03 source applicability decision](../contracts/PK22.TIMED-STATUS-043F.md) for the versioned historical layouts.

## Branch and lifecycle gates

- Cover PC/non-PC, hidden/burrowed/special-hiding, level 99/non-99, all showEFST masks listed above, duplicate effect suppression, priority among bits 1/2/4/0x4000, job-specific bit-0x20 animation, refresh without duplicate effects, end/removal, missing actor, and actor/map teardown.
- Validate each bit against the target profile's status enum and effect asset mapping before closing a row. No audit row is closed by this scope checkpoint.
