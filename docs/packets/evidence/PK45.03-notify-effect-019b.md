# PK45.03 — notification effect packet 0x019B

Date: 2026-11-04. Status: framing, server enum list and client effect mapping traced; unsupported result codes and replay remain open. No rows closed.

The selected server defines `0x019B` as `ZC_NOTIFY_EFFECT`, a 10-byte packet with actor ID u32 and notification-effect type u32 after the opcode. `clif_misceffect` fills those fields and broadcasts in AREA. The server documents codes for base/job level-up variants (including Super Novice and Taekwon), refine failure/success, game over, and pharmacy success/failure.

The client packet-size table also fixes 0x019B at 10 bytes. `HandleNotifyEffect` checks the active packet ID, resolves the actor, and maps five level-up codes to effect IDs; it suppresses duplicate local level-up notifications, launches the effect, and records local effects. Other codes fall through to an “unhandled” log and return, so the server-documented refine/pharmacy/game-over values do not receive this visual handling in this function. Whether separate UI paths cover those outcomes and whether the packet ID is active in the selected profile need source/capture review. No discovery row is closed.
