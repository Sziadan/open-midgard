# PK26.02 Warp and making-arrow lifecycle

- The production reader, router, and existing skill chooser replay a two-destination Warp offer, the making-arrow material list, and random-only Teleport. The socket peer verifies the exact selected and cancel frames for `011B` and `01AE`, including the automatic random-only response.
- Empty lists dismiss only their own chooser. An incoming nonempty making-arrow or AutoSpell offer replaces the local Warp state. The making-arrow replay keeps the socket connected during replacement so an unexpected old Warp cancel would fail the byte check.
- Disconnected Warp submit and making-arrow submit or cancel preserve the selection. A failed automatic random-only Teleport send exposes its destination for retry. A destination outside the current Warp offer is rejected.

Run the focused production replay with `ctest --test-dir build-mingw-preset -R packet_skill_choice_lifecycle_checks --output-on-failure`. The estimate portrait and Star Gladiator have separate work remaining. These fixtures exercise the client through a local socket peer.
