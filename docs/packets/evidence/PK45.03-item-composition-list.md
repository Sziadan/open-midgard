# PK45.03 — item composition equipment list

Date: 2026-11-04. Status: variable framing, item-index extraction and composition-window updates traced; selected-server semantics and replay remain open. No rows closed.

Opcode 0x017B is registered with variable-length framing and routed to `HandleItemCompositionList`. The handler requires data, at least the four-byte header, and an even payload after the header. It reads u16 item indices beginning at offset 4, skips zero values, and retains nonzero indices in packet order (including duplicates). The handler does not independently check the packet ID; the router supplies the registration context.

The parsed list is passed to `ShowItemCompositionWindow`. If the expected window can be created or reused, the helper reads the current game mode's last card item index (clamped at zero), sets that card index, then replaces the equipment item list. Failure to obtain the window stops the UI update. The handler sends no reply and does not otherwise mutate packet-derived game state.
