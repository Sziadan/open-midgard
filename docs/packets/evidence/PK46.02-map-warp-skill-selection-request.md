# PK46.02 — warp-skill destination selection request

Date: 2026-11-04; replay update 2026-11-05. Status: request, cancel sentinel, selected server skill-state gates, destination-name semantics, and production sender replay are documented. Live server/runtime outcomes remain unverified; no discovery row is closed.

The `0x011C` warp-map-list handler records the skill ID and destination names, then opens/refreshes the Warp selection in `UISkillSelectWnd` when destinations are available. Submitting a row calls `SendWarpMapSelection`. The sender rejects a missing skill ID, empty/overlong name, or name not present in the current destination list. It builds the active-profile `PACKET_CZ_USESKILLMAP` (20 bytes), sends it, and clears the pending skill/list only after a successful send. The packet contains opcode `0x011B`, skill ID u16@2, and a 16-byte fixed map-name field at offset 4; the builder copies at most 15 characters and leaves the final byte NUL.

Cancel follows a distinct wire path: `CancelWarpMapSelection` sends the same packet with the literal map name `cancel`; it clears pending state only when the send succeeds. The UI keeps the window open when selection/cancel sending fails and deletes it after success. This means the cancel sentinel is intentionally not subject to the normal destination-membership check.

The selected 20080910 server registry records `0x011B`, fixed length 20, parser `clif_parse_UseSkillMap`. This matches the client struct size and active profile opcode. The parser clears work-in-progress, checks the packet skill ID against `menuskill_id`, applies cast-state gates, and passes the map name through `mapindex_getmapname`. That helper copies the name and strips only an optional `.gat` suffix, preserving the literal lowercase `cancel`; `skill_castend_map` then compares exactly with `cancel`, clears `menuskill_id`/`menuskill_val`, and returns without casting (`src/map/clif.cpp:13152-13179`, `src/common/mapindex.cpp:24-40`, `src/map/skill.cpp:5457-5484`). This confirms the client cancel sentinel reaches the server cancellation branch. For AL_WARP, an unresolved map name produces index zero; the server sends `clif_skill_fail`, clears menu-skill state, and returns (`src/map/skill.cpp:5501-5514`). General map-name case matching depends on the map-index string DB lookup and remains for stronger review; destination response timing and runtime replay also remain open. No independent fixture or production replay was run; no discovery row is closed.
