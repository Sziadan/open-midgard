# PK45.03 — skill damage and no-damage notifications

Date: 2026-11-04. Status: client layouts and selected server active/inactive paths traced; branch selection, actor lifecycle and replay remain open. No rows closed.

## Damage notifications: 0x0114 / 0x01DE

The client maps `HandleSkillDamageNotify` to the short 31-byte `0x0114` form and long 33-byte `0x01DE` form. Both carry skill ID, source/target GIDs, tick, attack delays, damage, level, hit count, and action type; the long form widens damage from signed u16 to u32. The handler resolves both actors and delivers the corresponding skill-use action.

The selected server's active `clif_skill_damage` fills those fields, applies hallucination damage conversion, clamps the damage to the selected field width, and can hide WoE damage by sending hit count or zero. It also has disguise-specific AREA_WOS/SELF routing. The exact opcode/struct branch must be confirmed from the effective compile profile before choosing a golden byte contract.

## Position-damage notification: 0x0115

The client has a 35-byte `HandleSkillDamagePositionNotify` path with source/target, tick/delays, x/y, damage, level, divisions, and action. The selected server source contains a matching legacy `clif_skill_damage2` body only inside a block comment; no active emitter was identified. Treat this client variant as unsupported/unconfirmed for the selected server unless a matching build or capture proves otherwise.

## No-damage result: 0x011A

The client fixes `0x011A` at 15 bytes and `HandleSkillNoDamageNotify` reads skill ID, signed level/heal, destination/source GIDs, and result, then calls `DeliverUseSkill`. The selected server's `clif_skill_nodamage` fills these fields (zero source ID when absent), sends AREA, and adjusts destination/source IDs for disguised actors. These result notifications are distinct from damage-bearing 0114/01DE packets.

The server/client field families now have explicit references, but verify effective opcode branch, disguise combinations, missing actors, and action/visual timing with production replay. No discovery row is closed.
