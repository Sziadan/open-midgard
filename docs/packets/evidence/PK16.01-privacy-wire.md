# PK16.01 selected privacy packet contract

The selected rAthena checkout uses `PACKETVER=20080910`. The following three settings have separate server state.

- Equipment visibility uses `02D8` with a little-endian type 0 at offset 2 and a little-endian boolean at offset 6, for 10 bytes total. `clif_parse_configuration` stores the boolean in `show_equip` and `clif_configuration` replies with `02D9` and the same layout. Map entry sends `02DA`, a three-byte snapshot with `show_equip` at offset 2. It is enabled by the server's 20070918 guard. The selected reference's message 270 requests the inverse of the confirmed state. Both receivers update the equipment control and post the localized equipment notice.
- Recall refusal uses type 1 in `02D8/02D9`. The parser stores `disable_call` and map entry sends it as `02D9` type 1. Server skill paths consult it when recalling other characters. The reference receiver treats every `02D9` as equipment visibility, so dispatch on the selected server's type before changing a setting.
- Party invite refusal uses three-byte `02C8` and `02C9`. The request flag is 0 for allow and 1 for refuse. `clif_parse_PartyTick` stores `disable_partyinvite` and calls `clif_partyinvitationstate`, which also runs on map entry and is active for this version. `02C9` is primarily owned by PK15 and must be covered by the PK16 request-to-snapshot replay.

Source anchors are `clif_packetdb.hpp` at `0x02d8` and `HEADER_CZ_PARTY_CONFIG`, `clif.hpp::e_config_type`, and `clif.cpp::clif_parse_configuration`, `clif_configuration`, `clif_equipcheckbox`, `clif_parse_PartyTick`, and `clif_partyinvitationstate`. The restore calls are in `clif_parse_LoadEndAck`. Reference anchors are `Ref/GameModePacket.cpp::Zc_Config`, `Zc_Config_Notify`, `Zc_Party_Config` and the message 270 caller in `Ref/GameMode.cpp`.
