## Client path

The packet-size table fixes 0x0148 at 8 bytes, and the router maps it to `HandleActorResurrection`. The handler requires 8 bytes, reads nonzero GID u32@2, and ignores bytes 6–7. If the actor is already present, it sends internal actor message 98. That message clears the actor's will-die/vanish/lie-on-ground/motion-finished/frozen flags, resets attack/state motion, restores pick-info eligibility, and invalidates a PC billboard. If the GID is the local player, the handler additionally clears quest state, local dead state, and the pending use-item acknowledgment flag. It does not create a missing actor.
