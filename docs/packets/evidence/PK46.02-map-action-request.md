# PK46.02 — map continuous-attack request

Date: 2026-11-05. Status: client click/retry path, profile serialization, selected parser, and unit-attack semantics source-traced. Runtime/replay effects remain open; no discovery row is closed.

## User action to sender

`WinMain.cpp` forwards left-button input to `CGameMode::OnMessage`. After pending-skill and ground-item handling, a click on a monster-like hovered actor reaches `TryRequestAttackFromScreenPoint`, which calls `SendAttackRequestPacket(hoveredActor->m_gid, kActionRequestContinuousAttack)`. The action constant is `0x07`; target ID zero is rejected for the single/continuous attack actions. The attack-chase update path can resend the same continuous action on its retry interval, both when the target is in range and while the client is chasing it.

## Client profile layouts

`ActionRequestSender.cpp` delegates to `BuildActiveActionRequestPacket` using the active `MapGameplaySendProfile` selected from `Packets.MapGameplaySendProfile` (default `inherit`; explicit PacketVer22/PacketVer23 and legacy tokens are supported).

- PacketVer22 uses `0x0190` and `PACKET_CZ_ACTION_REQUEST_PACKETVER22`, 19 bytes total: opcode at 0–1, padding at 2–4, target GID u32 at 5–8, padding at 9–17, action at 18. The builder fills both padding arrays before copying the struct.
- PacketVer23 uses `0x0437` and `PACKET_CZ_ACTION_REQUEST2`, 7 bytes total: opcode at 0–1, target GID u32 at 2–5, action at 6.
- The explicit legacy profile selects opcode `0x0089` with the compact seven-byte action struct (`src/network/MapSendProfile.cpp:158-186`). The selected 20080910 registry assigns `0x0089` fixed length 8 to `clif_parse_TickSend`, with client tick at offset 4 (`PK01.02-server-registry-final.csv:373`). Thus the legacy seven-byte action frame conflicts with the selected server opcode identity and length; do not treat that configured branch as supported without a corrected profile and production replay.

## Selected server contract and open work

The pinned server registry at effective `PACKETVER=20080910` registers `0x0190` as 19 bytes with target/action offsets 5/18, and `0x0437` as 7 bytes with offsets 2/6. Both go through `clif_parse_ActionRequest`; the corresponding PK01 contracts approve applicability/layout, not action-branch semantics. For the two PacketVer profiles, the client field positions and lengths match these registrations. The server contract reads target as signed int32 whereas the client serializes u32; confirm that the selected action branch accepts the client target domain and action value `0x07`. Parser restrictions, range/timing behavior, responses, and whether retries match the server lifecycle remain open. The legacy `0x0089` path also needs an applicable server contract. No packet-specific production replay or live UI acceptance was run; this single request does not close PK46.02.

## Selected continuous-attack branch follow-up — 2026-11-05

At PACKETVER=20080910, the selected parser's 0x0437 layout supplies target at offset 2 and action at offset 6; clif_parse_ActionRequest passes those values to clif_parse_ActionRequest_sub. DMG_REPEAT is enum value 7, matching this client's continuous-attack action. It is one of the two action types that bypass the nonattack interaction-block branch, but the server still rejects a dead requester, missing/dead target, unit_can_attack failure, invalid enemy relationship, and blocked skill use. It calls unit_attack(&sd, target_id, true) for the accepted continuous request.

unit_attack resolves the signed int32 target through map_id2bl, rejects missing/dead or unattackable targets, sets continuous-attack state and target, and enables auto-chase. If an attack timer already exists, it returns without scheduling a duplicate timer; subsequent client requests can update the requested target/type. The client's u32 wire encoding matches the server's signed read for normal positive block IDs in the representable int32 domain. The disguise-self negative-ID exception is server-specific; arbitrary high-bit u32 targets are not proven valid and are not inferred to be.
