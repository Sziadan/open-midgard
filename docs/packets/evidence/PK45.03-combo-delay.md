# PK45.03 — combo delay animation tick

Date: 2026-11-04. Status: fixed framing, session cache and actor propagation traced; lifetime semantics and replay remain open. No rows closed.

The size table fixes 0x01D2 (`ZC_COMBODELAY`) at 10 bytes and the router maps it to `HandleComboDelay`. The handler reads AID u32@2 and tick u32@6, stores the pair with `g_session.SetForceAnimEndTick`, then resolves the actor and applies the tick directly when present. It stores the session entry even if the actor/world cannot be resolved.

The session cache updates the first matching AID or appends a new entry; a lookup returns the stored tick or u32(-1) when absent. Actor skill-action message case 272 later reads this cache when constructing its forced animation. The handler does not validate AID/tick, remove entries, or emit UI/effects directly.
