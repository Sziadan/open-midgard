# PK45.03 — item identification list

Date: 2026-11-04. Status: variable framing, item-index extraction and identify-window reset traced; selected-server semantics and replay remain open. No rows closed.

Opcode 0x0177 uses variable-length framing and is routed to `HandleItemIdentifyList`. The handler requires non-null packet data, a four-byte minimum header, and an even payload length after the header. It reads u16 item indices from offset 4, skips zero values, and preserves the order and duplicates of all other indices. It does not separately compare the packet ID against 0x0177; dispatch provides the route.

The list replaces the identify window's item indices. If the window is available, its setter resets hovered and selected indices, scroll offset and dragging state, refreshes interaction state and invalidates the window for redraw. The handler sends no reply and performs no other state update.

Open work: confirm the header/item-index meaning and duplicate/order semantics against the selected server/profile; replay empty, malformed and repeated-index lists and verify selection reset, window creation/reuse and interaction behavior. No independent fixture or production replay was performed for this leaf.
