# PK44.04 — Correct login refusal result messages

Date: 2026-11-04. Status: bounded production framing, dispatch and result mapping verified; PK44.04 remains in progress.

## Source contract

The selected rAthena `PACKET_AC_REFUSE_LOGIN` layout is 23 bytes: opcode `0x006A` at offsets 0–1, one-byte error at offset 2, and 20 unblock-time bytes at offsets 3–22. In `src/login/loginclif.cpp`, `logclif_auth_failed` zero-initializes the packet, assigns the error value, and copies an empty string into `unblock_time` before sending. Its result comments define meanings for codes 0–8 and 99–104. Codes 9–15 use named MSI refusal results; selected English `conf/msg_conf/login_msg.conf` supplies their default labels and also distinguishes the log messages associated with 99–104. These are source-default labels, not proof that a deployed server has unmodified message configuration.

The selected server currently empties the unblock-time field even when its auth wrapper supplies a date, so nonempty-date formatting is not claimed as server-path coverage.
