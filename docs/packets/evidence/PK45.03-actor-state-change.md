# PK45.03 — actor state-change receive handler

Date: 2026-11-04. Status: client packet layouts and state handoff traced for the current receive profile. selected-server profile branch traced; downstream status/cart lifecycle and replay remain open. No rows closed.

## Current client layouts and branch

`MapSendProfile` exposes basic actor-state packet 0x0119 and extended packet 0x0229. The client packet-size table assigns fixed sizes 13 and 15 bytes respectively. Both register to `HandleActorStateChange`. The basic form reads GID u32@2, body state u16@6, health state u16@8, effect state u16@10, and PK state u8@12. The extended form preserves those leading fields, reads effect state as u32@10, and PK state u8@14. The handler checks the corresponding minimum size and branches based on whether the packet ID is the active extended variant.

After decoding, the handler records the GID in `m_aidList`, ensures a runtime actor, and sends body/effect/health/PK values through actor message 43. For the local player it also updates known cart state from effect flags, invalidates cart UI when the push-cart state changes, and applies pending local cart state. The exact visual/status transitions are owned by the PK22 status lifecycle work and were not independently replayed here.

## Server/profile boundary

The selected packet struct and clif_changeoption_target now resolve the variant boundary: below PACKETVER 7 the server defines the 13-byte 0x0119 form with a 16-bit effect field; at PACKETVER 7 and above it defines the 15-byte 0x0229 form with a 32-bit effect field. The pinned effective PACKETVER=20080910 selects 0x0229. The receive profile still supports both IDs, but 0x0119 is not the selected server emitter under this baseline.

## Selected server state-change variant boundary (2026-11-04)

The pinned src/map/packets_struct.hpp selects PACKET_ZC_STATE_CHANGE opcode 0x0229 at PACKETVER >= 7 and opcode 0x0119 below that threshold. The legacy 0x0119 record is 13 bytes with a 16-bit effectState; the selected 20080910 0x0229 record is 15 bytes with a 32-bit effectState. Both carry actor ID, body state, health state, and PK-mode flag. This confirms map-stage S2C ownership for 0x0119 as a legacy variant and distinguishes it from the selected 0x0229 emitter.
