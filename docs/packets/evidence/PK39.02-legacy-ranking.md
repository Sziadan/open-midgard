# PK39.02 legacy ranking

The effective MAIN 20080910 registry maps `0217`, `0218`, `0225`, and `0237` to the Blacksmith, Alchemist, Taekwon, and Killer ranking parsers. All four requests are two bytes. The existing source chat command path sends the first three. `/pk` now routes through the reference's mode message 201 and sends `0237`.

The selected `clif_ranklist` sends `0219`, `021A`, `0226`, or `0238` to the requester. Each is 282 bytes. Ten 24-byte names start at byte 2, followed by ten four-byte point values at byte 242. The selected server fills the Killer list with `Unavailable` and zero points because that ranking has no data source. The client displays the rows received from the server. It follows the reference's row formatting and colors and uses English headings and a separator pending exact heading text verification.

`clif_update_rankingpoint` can emit `021B`, `021C`, `0224`, and `0236`. Each is ten bytes with the point delta at 2 and total at 6. `pc_addfame` supplies a signed delta and reaches the first three types. The selected source has no Killer caller in `pc_addfame`. OldRO's `data.grf` supplies notice entries 901, 902, 926, and 953. Entry 953 has a malformed first placeholder, so the client uses the fallback for that entry. The selected profile uses these separate packets, while the unified request requires a later profile.

Replay covers all four lists and point updates, a full-width final name, a negative point delta, and `/pk` submission through the production slash-command path. Live ranking output remains open.
