## PK47.04-DIGIT-CLOCK

The selected map packet registry lists `01B1` at seven bytes. rAthena `src/map/clif.cpp:19019` writes the type at offset 2 and a little-endian signed 32-bit value at offset 3. The `showdigit` script command in `src/map/script.cpp:22745` makes types 1 and 2 negative offsets and limits type 3 to 99. The Bakonawa Lake script calls the command when counting the remaining monsters.

The selected `Zc_ShowDigit` and `DrawTime` routines are in `Ref/GameModePacket.cpp:25317` and `Ref/GameMode.cpp:9654`. Type 0 displays a fixed duration through the first frame more than five seconds after its first draw. Type 1 counts up from the supplied offset. Type 2 counts down and retires on a frame at the exact zero tick, with 32-bit wrap if that tick is skipped. Type 3 starts at `30 * value + 29` and decrements once per gameplay render, displaying zero once. Duration fields are two digits per group with colon separators and zero padding through the largest present unit.

The original stores the counter in the session and the static start time in the gameplay mode. The rebuild likewise retains the counter during map transitions, restarts the first-draw timer when the mode is recreated, and clears it on entry to login. An unknown type is ignored. The original can re-enable previous state for that type, which the selected script command does not emit.

The selected executable points to the CP949 `이팩트\TimeFont.spr` and `TimeFont.act` paths at virtual addresses `0x7121CC` and `0x7121E0`. The installed `data.grf` contains both under `data\sprite`. The gameplay renderer uses the first motion of actions 0–9 and colon action 10. The first anchor is `rendererWidth / 2 - 40 * glyphCount / 2`, the row is anchored at y=40, and each step is 40 pixels. The clock shares the gameplay overlay pass across UI modes.

The production packet replay covers all four modes, signed offsets, strict static expiry, tick rollover, the short countdown render cadence, an unknown type, and incomplete framing. The opt-in `--digit-clock-render <data.grf>` replay passed with the installed OldRO archive and Vulkan. It checks texture creation, queued geometry, resizing, and expiry.
