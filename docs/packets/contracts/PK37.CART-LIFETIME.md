# PK37.CART-LIFETIME — selected cart contents, status and presence

Owner: PK37. Bounded leaf: PK37.05. Status: IMPLEMENTED_PENDING_REVIEW.
Profile: source-selected PACKETVER 20080910; independent PK48 and deployed acceptance remain open.

## Wire and state ownership

- `0121`, 14 bytes: count/capacity u16 at 2/4, weight/max-weight u32 at 6/10. These counters are authoritative independently of item rows. Qt divides raw weights by ten once. Zero items/weight still describes an existing cart.
- Selected list routes `02E9`/`02D2` retain the existing PK09 list contracts. A list is not a counter update.
- `01C5`, 22 bytes: index u16 at 2, amount u32 at 4, item ID u16 at 8, type/identified/damaged/refine bytes at 10/11/12/13, four u16 cards at 14. A new index copies carried fields. An existing index increments quantity only, preserving its complete old record, as primary `CSession::AddMerchantItem` does. No location/expiry/bind fields exist in this delta.
- `0125`, 8 bytes: index u16 at 2, amount u32 at 4. Partial subtraction retains the row; full subtraction removes it. Neither addition nor deletion rewrites status counters.
- `012C`, 3 bytes: result 0 means weight failure, 1 means capacity failure. Unknown results are ignored; failures do not change rows or counters.
- `012B`, 2 bytes: clear cart contents and close its window; retain presence and count/weight. Primary `Zc_Cartoff` and selected server `clif_clearcart` agree. Retained entitlement allows the actual Cart button to reopen an empty window pending fresh data.
- Legacy local actor option state owns cart removal. Selected `0119`, 13 bytes: GID u32 at 2, body/health/effect u16 at 6/8/10, PK byte at 12. Cart masks are 0008/0080/0100/0200/0400. Remote actor options cannot change local entitlement. `pc_setoption` sends the option update before the clear-contents packet. Selected `NEW_CARTS` is undefined; later status-based cart rules must not be imported.
