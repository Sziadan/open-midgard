## Typed source interface

Source manager messages1/20 are distinct from the modern event101 and modern channel numbers. `NoticeRoute` retains1 normal/20 command; `NoticeType` retains source numeric0..13. The manager's source-compatible SendMsg overload shape carries text, COLORREF, type and optional talker. `PushSourceChatEvent` instead accepts an already converted UI RGB color plus independent modern visual channel and explicit source metadata. Default zero source color becomes white. Original COLORREF16776960 is cyan, converted to0x0000FFFF;255 converts to UI red0x00FF0000. Do not reassign source type from a visual channel or convert an already converted UI color twice.

When main exists, manager1/20 filter exact case-sensitive strings `NO MSG` and `No Msg`. Other case variants pass. The main parser itself has no sentinel filter; direct child37/115 therefore accept those strings. Empty text produces no split rows. Manager notices do not expand the main window. Explicit manager3 is a separate create/show/conditional-expand operation and must remain separate even if a producer's language text is empty.

The parser retains optional talker, replacing it with the prefix before the first ` :` for types1/3/4 when the prefix is nonempty. Germany/Vietnam reject over24-byte talkers; matching self name clears the talker. Other services use owned strings rather than reproducing the original unsafe fixed-buffer copy.

## Stream and retention rules

The13 session battle-message option bytes default true. Normal/event37 inserts ST unless type8/9 suppress it. It additionally inserts BT only for a nonzero selected type whose option[type-1] is enabled. Command/event115 inserts BT directly and bypasses that option check. None/type0 from a normal route is ST-only. The selected13-type domain is evidence for safe option indexing; later header enum extensions are not selected-PE applicability proof.

Main ST/BT own separate text/color/talker row vectors. They drop the oldest half when size reaches240 BEFORE append. Detached owners independently retain their own copied rows and apply the same half-trim. For each split iteration, main receives the current segment while detached history receives the original UNSPLIT text again. Preserve that observed source quirk.

CutString uses a94-byte-distance threshold and remembers the position after a run of spaces; output preserves those spaces. A space run or multibyte character can cross94, so94 is not a hard truncation limit. The current UTF-8 port advances complete UTF-8 character boundaries in place of source CharNextExA. ASCII source behavior and UTF-8 preservation have independent literal checks. Full legacy codepage/Thai wordbreaking and charset-tag behavior remain locale work, not established by these tests.

## Absent and recreated main

With no main, source notices append split text/color to a separate retained manager backlog. It has no ST/BT route or talker identity, and source creation does not replay it. Live typed receipts have the generation of their owning main; absent receipts have no owner generation. The manager256-event receipt cache and old primary50-line diagnostic cache cannot replay or reclassify either absent or destroyed-owner source receipts into a new main. Unknown modern events remain a separate unreviewed representation; do not infer source categories from them.

Individual main deletion does not destroy retained auxiliary owners. Qt auxiliary projection is independent of main visibility, and its native input gate is independent of main availability while respecting the existing modal/editor-grab policy. Actual native/QML frames verify the retained-owner interval. Active Qt embedding capture/overlap acceptance remains open.
