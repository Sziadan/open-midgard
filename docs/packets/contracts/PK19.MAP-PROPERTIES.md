`Ref/GameModePacket.cpp:18275` restores the saved minimum-effect preference on `0199`. Values 1 and 5 set PK, 2 sets event PvP, and 3 sets siege and forces minimum effects. Value 4 sends localized notice 855 with COLORREF `0x9B9BFF`, confirmed in the selected executable at `0x5A5315`. Non-Korean services clear the map-type table. `Ref/GameModePacket.cpp:18311` retains the signed map type from `01D6` and restores the saved minimum-effect preference. Types 5 and 6 set PK. Types 11 and 12 skip siege and battleground changes. The selected client's game-mode initialization constructs a fresh world, which zeroes PK, siege, battlefield and event PvP. The port reuses the global world and resets those flags at real mode entry. Loaded same-map `0091` reuse keeps the existing flags. Map type and the saved minimum-effect preference are session fields. The next property packet restores the effective preference before applying any force flag. [Lifecycle evidence](../evidence/PK19-map-property-lifetime.md)

`Ref/Session2.cpp:5479` reads `MapInfoTable.scp` as a flat sequence of up to 450 integers with a stride of 15. Party ally, guild ally, and siege lookups use columns 7, 8, and 9. The port bounds-checks types and keeps zero defaults when the table is absent or short. The inspected OldRO `data.grf` entry contains 110 values in ten-column physical lines. The executable uses its fifteen-value stride independently of those lines.

The selected executable's variable `02E7` receiver at `0x5B2F30` uses the length at offset 2 and a signed map type at offset 4. It starts at that type's first table entry, reads a decimal value from each successive byte position after offset 6, and advances through the flat table. Adjacent digits therefore contribute to each decimal suffix. The port terminates reads at the frame boundary and rejects updates whose starting type or full span falls outside the table. A valid update changes table entries without changing the selected type or recalculating the world's flags.

The selected rAthena source registers `02E7` as a variable frame with no parser at `src/map/clif_packetdb.hpp:957`. The local source scan found the registry entry and no emitter.
