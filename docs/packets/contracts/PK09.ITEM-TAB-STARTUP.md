# PK09 inventory tab startup and retention

Reference startup is not generic last-tab restoration. Ref/WinMain.cpp:215 initializes UI records once after renderer size is set. Ref/UIWindowMgr.cpp:10852-10862 defaults the records if the UI registry key is absent. After successful reads, lines10909-10915 overwrite inventory x/y/w/h/orgHeight/tab with744/514/280/134/134/1. This late override supersedes the earlier registry tab read, even if that stored tab was invalid.

Ref/UIItemWnd.cpp:4368-4388 validates the complete manager record before applying its tab. Ref/UIRectInfo.cpp:485-502 checks full viewport containment, tab0..2 and radios0..3/0..3/0..4; invalid records default to tab0 (1258-1269). The forced rectangle fits at1024x648. Initialized radio groups remain All3/3/4. Ref/UIItemWnd.cpp:11513-11531 writes current tab into the manager record; same-process reuse/recreation therefore retains selection. Registry writes alone do not establish cold-start behavior.

The current INI adapter treats presence of [UIWindows] as the reference UI registry-key presence. Missing optional radio fields retain initialized All values; present malformed/out-of-range radios invalidate the startup selection. The first inventory selection uses the current logical viewport: absent record, undersized viewport or invalid radios selects0; valid warm record selects1, ignoring saved ItemWndTab. Manager runtime state is then canonical for native inventory, Qt commerce and map-entry retention. Closing/deleting stores the current tab and initialized radios; recreating in the same process uses the manager state rather than re-reading the disk tab. Storage stays independently initialized to0: its source StoreInfo/registry representation saves geometry only.

This leaf accepts tab policy and shared selection only. It does not apply the reference744/514 placement to the current UI or certify full legacy geometry, whole-record invalid saved-geometry coupling, mini/orgHeight, detail default placement, scaling equivalence or resize behavior. Tests use100% scale with hidden Windows viewport fixtures; production adapts to logical UI bounds. Do not infer full PK09.04 acceptance from this checkpoint.
