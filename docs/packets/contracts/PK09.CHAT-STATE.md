Child2 cycles only while sticky. PE0x49E52C uses NEG EAX, SBB EAX,EAX, AND AL,FE, INC EAX; AND AL does not zero-extend. The signed candidate is-1 from state0 on decrease, or state-3 otherwise; positive candidates use `candidate+1-candidate%3` before normalization. Decreasing from0 therefore yields15. Independent literal fixtures cover all32 transitions.

Child14 acts only for type2 and sticky mode. The requested physical parent height is captured by UIResizer::OnLBtnDown and adjusted by its RT_UP pointer delta before dispatch (Ref/UIControl.cpp6808–6912). Below72 collapses; otherwise state is `min(15,(height-72)/14+1)`. This source quantization is not the inverse of displayed height; preserve it. Child15 sets state directly. Child16 expands to1 only when sticky and collapsed.

Manager2 forwards child15 to an existing chat. Manager3 uses source ShowWindow semantics: create/show main chat, then child16. Ordinary modern chat-event insertion101 does not expand.
