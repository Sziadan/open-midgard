## Main state behavior

SetState0x49CA80 normalizes negative requested states to15 and requests above15 to0. State0 is24px high. States1–15 have height `16+24+14*(state+3)`, giving96–292px. Preserve the previous bottom edge and do not undo that anchor by clamping the next OnProcess position.

Child2 cycles only while sticky. PE0x49E52C uses NEG EAX, SBB EAX,EAX, AND AL,FE, INC EAX; AND AL does not zero-extend. The signed candidate is-1 from state0 on decrease, or state-3 otherwise; positive candidates use `candidate+1-candidate%3` before normalization. Decreasing from0 therefore yields15. Independent literal fixtures cover all32 transitions.

Child14 acts only for type2 and sticky mode. The requested physical parent height is captured by UIResizer::OnLBtnDown and adjusted by its RT_UP pointer delta before dispatch (Ref/UIControl.cpp6808–6912). Below72 collapses; otherwise state is `min(15,(height-72)/14+1)`. This source quantization is not the inverse of displayed height; preserve it. Child15 sets state directly. Child16 expands to1 only when sticky and collapsed.

Manager2 forwards child15 to an existing chat. Manager3 uses source ShowWindow semantics: create/show main chat, then child16. Ordinary modern chat-event insertion101 does not expand. Original manager1/20 and child37/115 stream integration remain pending; current channel IDs0–6 are not a stream oracle.

The captured main frame rejects state changes. Native input has the manager pointer; Qt frame dragging has its own armed/dragging state. The port's inline resize/slider captures represent source child-control captures and do not freeze the main frame. Cancelled capture clears local state and the matching manager pointer; the Qt window-message notification path invokes it for WM_CAPTURECHANGED/WM_CANCELMODE before the runtime-active guard. Input text/focus data is retained.
