# PK26 selected special skill information and choices

The configured rAthena source selects `PACKETVER=PACKETVER_SAK_NUM=20080910`. The [header probe](../evidence/PK26.01-choice-layout-probe.cpp) verifies the selected packed layouts. For manually written packets, use the effective packet database and the emitter or parser below. `@` marks a byte offset.

## Memo and monster estimate

- `011E` is three bytes. `clif_skill_memomessage` sends result u8@2 to SELF from `pc_memo`. The selected enum is 0 stored, 1 low skill level, and 2 Warp skill unlearned. The Ref `Zc_Ack_Remember_Warppoint` notice distinguishes success and failure colors. `011D` is the selected memo request. Map restrictions can use separate server notices and do not add `011E` result values.
- `018C` is 29 bytes. `clif_skill_estimation` sends monster class/level/size u16@2/@4/@6, HP u32@8, DEF s16@12, race u16@14, MDEF s16@16, element u16@18, and nine u8 percentages@20–28 in water, earth, fire, wind, poison, holy, shadow, ghost, undead order. It targets the party on the same map or SELF. The Ref window is `WID_MONSTERINFOWND`, 400×200, and receives the packet through message 79. The Ref entry rejects classes 1285–1287, 1829 and 1830. Preserve the full HP width, use bounded resource lookups, and verify refresh and close through the existing window manager. [Ref rendering and factory anchors](../evidence/PK26.01-selected-layout.md)

## Warp, making arrow and AutoSpell

- `011C` is the selected fixed 68-byte list. It contains skill u16@2 and four 16-byte map name slots@4. `011B` is the 20-byte response with the skill and one 16-byte name. The server recognizes `cancel` and validates the current menu and offered map. The later variable `0ABE` form is outside this profile. Keep pending state on a failed request and clear it when a successful submission or source-backed cancellation resolves the offer. [Existing sender replay](../evidence/PK46.02-map-warp-skill-selection-request.md)
- `01AD` is a variable-size making-arrow offer with length u16@2 and item u16 rows starting at byte 4. `clif_arrow_create_list` emits the eligible owned material choices and enters the arrow menu state when it offers any. `01AE` is the four-byte response with item u16@2. The server parser uses the active menu to distinguish arrow creation and other reuse of that response. Keep this chooser bound to the current arrow offer and check replacement, malformed payload and failed send.
- `01CD` is the selected 30-byte AutoSpell list. `clif_autospell` writes seven s32 skill slots@2–29, with zeros for unavailable entries. `01CE` is six bytes with skill u32@2. `clif_parse_AutoSpell` requires `SA_AUTOSPELL`, then narrows to the server's u16 skill ID before running the selection. Offer only representable nonzero IDs from the current packet. The Ref appends each nonzero slot to the existing model. Treat the selected server list as a replacement offer so stale entries cannot be submitted. The selected version does not use modern variable `0AFB` or the later generic skill-selection response.

## Feeling, Hatred and mission

- `020E` is 32 bytes in the selected effective packet database. `clif_starskill` writes 24 text bytes@2, a signed dword@26, star/progress u8@30 and result u8@31. The selected wrappers emit results 0/1 for Feeling map registration/info, 10/11 for Hatred registration/info, 20 for TaeKwon Mission and 30 for reset. The text is a map, job, or monster name according to the wrapper. The general Ref switch has extra branches. Only the listed wrappers are proven selected emitters in this tree. The Ref result path sends a broadcast balloon and applicable chat presentation.
- `0253` is the three-byte confirmation from `clif_feel_req`, with which u8@2 in 0–2. The server retains the skill and level in its menu state. `0254` is the three-byte accept from the Ref confirmation window via mode message 205. The server requires `SG_FEEL`, bounds its retained level, saves the current map, emits `020E` and clears its menu. Ref Cancel closes the prompt without a request. Keep acceptance tied to the current prompt, preserve it on send failure, and scope lifecycle to the map/session. The Ref uses the same window for another feature with selector 10. The selected Feeling emitter supplies only 0–2.
