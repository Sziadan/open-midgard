# PK18.MAP-CELLS

Status: IMPLEMENTED_PENDING_REVIEW. Discovery parent: AUDIT-0x0192. Owners: PK18.01 through PK18.04. Independent PK48 review is pending.

The selected local rAthena MAIN 20080910 source sends `ZC_UPDATE_MAPINFO` from `src/map/clif.cpp:5363` using the packed definition in `src/map/packets.hpp:1782`. It is a map-stage server-to-client frame. The [selected source trace](../evidence/PK18.01-dynamic-map-cell-scope.md) records Ice Wall placement, removal, area entry and exit, invisible walls, and the GM sender. The source configuration is pinned by [PK01.02](../evidence/PK01.02-server-registry-assignments.txt). The deployed server binary was outside this verification.

The frame is exactly 24 bytes.

1. Offset 0 is the unsigned little-endian 16-bit opcode `0192`.
2. Offsets 2 and 4 are signed little-endian 16-bit X and Y in GAT cell coordinates. Valid positions start at zero and must fit the target GAT dimensions.
3. Offset 6 is the signed little-endian 16-bit GAT type. Types 0, 2, 4, and 6 are walkable, shootable and dry. Type 1 blocks walking and shooting. Type 3 is walkable, shootable and water. Type 5 blocks walking and permits shooting. These values come from server `map_gat2cell`.
4. Offset 8 is a 16-byte map field written by `mapindex_getmapname_ext` into the zero-initialized frame. Read up to the first NUL or the field boundary, then normalize case and the map extension for comparison.

The server layout encodes a type 5 update to Prontera cell (156, 184) as `92019c00b800050070726f6e746572612e67617400000000`. A restoration to type 0 replaces the two bytes at offset 6 with `0000`.

The selected client at `0x5A4440` changes the GAT cell flag while preserving heights and ground geometry. The port keeps the base resource immutable and rejects unsupported types, invalid coordinates, and foreign or empty map names. Matching updates arriving before GAT binding are coalesced by coordinate, then checked against actual bounds. Loaded same-map warp reuse retains the world state. Replacement or exit clears it. Movement, skill approach and the hover renderer use the effective cell. Ice Wall unit placement and removal use their own packet path.
