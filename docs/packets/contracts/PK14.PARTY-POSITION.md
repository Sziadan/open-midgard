# PK14.PARTY-POSITION — selected party minimap coordinates

Status: IMPLEMENTED_PENDING_REVIEW. Discovery parent: AUDIT-0x0107. Owner: PK14; implementation verification PK14.04. Global PK48 independent review remains pending. This is selected-source implementation/verification, not deployed-server binary provenance or an original-client skin certificate.

## Identity and bytes

Map S2C 0x0107, fixed **10 bytes**, no length field or reply. Selected PACKETVER/SAK/MAIN is 20080910, established by the existing source baseline and independently compiled [guarded layout probe](../evidence/PK14.04-position-layout-probe.cpp), [output](../evidence/PK14.04-position-layout-probe.txt). The external server is the pinned unversioned local rAthena snapshot, not Ref's bundled server. Current source hashes and effective-wrapper identity are retained with [verification provenance](../evidence/PK14.04-rendered-acceptance.json).

1. Offset 0, u16 little endian: opcode 0x0107.
2. Offset 2, signed i32 little endian in `PACKET_ZC_NOTIFY_POSITION_TO_GROUPM::AID`: account ID, not character GID. The client retains the corresponding positive server account-ID bit pattern as u32 and updates only an existing party member. Zero/unknown IDs do not create actors or membership.
3. Offset 6, signed i16 little endian: X in map cells. Valid ordinary protocol values are 0..32767; no packet-defined pixel scale exists.
4. Offset 8, signed i16 little endian: Y in map cells. Same ordinary range. The pair **(-1,-1)** removes a marker. Half-sentinels and other negative coordinates are rejected without partial mutation.

Independent source-derived examples: AID 42 at (50,70) is `07012a00000032004600`; its removal is `07012a000000ffffffff`. The server struct is packed; compile-time size/signedness/offset assertions prove 10/2/6/8. The selected server input registry has no 0x0107 entry or C2S parser. Active typed S2C emitters send sizeof(p)=10 directly; absence from that input registry does not imply inactivity. The client framing table independently registers ten bytes. `clif_party_xy`, `clif_party_xy_single`, and `clif_party_xy_remove` emit the ordinary/sentinel forms; party map synchronization/removal callers establish same-map reachability. See the source anchors and selected hashes in PK14.01 and the new provenance.

## State and lifetime

Production framing/router selects `HandlePartyPosition`, which requires exactly ten bytes, reads AID/X/Y, rejects unknown membership and non-sentinel traffic for offline/other-map members, then updates session-owned coordinates. Sentinel removal is allowed without fabricating a successful map transition. Coordinates are retained only for compatible online members across same-AID/normalized-map roster refreshes. Full roster replacement is validated atomically; missing members, changed identity/map or offline state cannot retain a dot. Incremental offline-to-online refresh cannot revive cached coordinates without fresh position traffic.

Actual map change, same-map reuse, server move, reconnect failure, initialization/exit and character selection invalidate coordinates while preserving appropriate membership. `OnNotifyZonesvr` invalidates before adopting a new GID/map. Native and Qt share `IsPartyMarkerEligible` and the position revision used by the visual token. Existing minimap geometry projects cells; no wire-value multiplier or new coordinate system is introduced.

## Visible behavior and acceptance

Native executes real `UIRoMapWnd::OnProcess`/`DrawToHdc`; Qt executes the production minimap adapter and `GameOverlay.qml` repeater with the real background-image builder. Eighteen saved native/QML scenes prove visibility, movement without stale pixels, stationary roster preservation, offline/online behavior, sentinel and roster removal, wrong-map rejection, guild/player layering, clipping at the left map edge, map transition, both reconnect outcomes and a session boundary. The fixture uses a synthetic bitmap and real world attribute bounds, not installed assets or invented marker circles.

The rendered review found and fixed two defects: packed RGB was being passed directly as Win32 COLORREF (red/blue reversed), and native dots could bleed outside the map rectangle. Native now converts RGB explicitly and clips the marker pass like QML. Existing native player-circle and Qt player-arrow styles remain distinct; the test checks their correct layer order rather than claiming identical skins.

[Acceptance report](../evidence/PK14.04-rendered-acceptance.md) maps source/state/caller/render evidence and limitations. Integrated validation passed 3/3: all 159 packet records, assertion-enabled standalone state cases and all 18 actual rendered scenes. PK48/PK49 and deployed-server/live acceptance remain separate; this contract closes only the selected 0x0107 implementation scope.
