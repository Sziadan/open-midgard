# PK23 selected skill receive contract

The server is the configured local rAthena source at `C:/Users/sziad/source/repos/rathena-master`. The [direct header probe](../evidence/PK23.01-skill-layout-probe.cpp) asserts `PACKETVER` and `PACKETVER_SAK_NUM` of `20080910`. In the layouts below, `@` introduces a byte offset and `s` and `u` mark signed and unsigned fields. Each frame begins with the two-byte opcode. `src/network/MapSendProfile.cpp::MakePacketVer23ReceiveProfile` and `RegisterDefaultGameModePacketHandlers` define client reachability. The server's selected emitters define selected traffic.

## Damage, ground results and target results

- **`01DE`, 33 bytes.** `PACKET_ZC_NOTIFY_SKILL` in server `src/map/packets_struct.hpp:4658` has skill u16@2, source and target u32@4/@8, tick u32@12, attack and attacked delays s32@16/@20, damage s32@24, level and hit count s16@28/@30, action s8@32. `clif_skill_damage` fills these fields, applies presentation damage conversion and width limits, and has ordinary, disguise and guild-war damage branches. Preserve signed levels, including the sentinel values supplied by server skill callers. Client route `HandleSkillDamageNotify` and Ref `Zc_Notify_Skill2`.
- **`0114`, 31 bytes.** The server header's `PACKETVER < 3` branch has damage s16@24, level and count s16@26/@28, action s8@30. This is a reachable client compatibility handler and the Ref `Zc_Notify_Skill` form. The selected server emits `01DE`.
- **`0115`, 35 bytes.** The position-damage header has skill u16@2, source and target u32@4/@8, tick u32@12, delays s32@16/@20, cells s16@24/@26, damage, level and count s16@28/@30/@32, action s8@34. Server `clif_skill_damage2` is commented out in the configured tree. Preserve client compatibility in `HandleSkillDamagePositionNotify` against Ref `Zc_Notify_Skill_Position` and track its replay independently of selected traffic.
- **`0117`, 18 bytes.** `PACKET_ZC_NOTIFY_GROUNDSKILL` has skill u16@2, source u32@4, level s16@8, cells s16@10/@12 and tick u32@14. `clif_skill_poseffect` emits AREA, or AREA_WOS plus a disguised source ID to SELF. Server skill callers can send level `-1` to suppress the name. Client `HandleGroundSkillNotify`, Ref `Zc_Notify_Groundskill`.
- **`011A`, 15 bytes.** `PACKET_ZC_USE_SKILL` has skill u16@2, level/heal s16@4, target u32@6, source u32@10 and result s8@14. `clif_skill_nodamage` can send source zero, caps the heal value to the field width and substitutes disguised source/target IDs per recipient. The later `09CB` form widens the level/heal and is outside the selected profile. Client `HandleSkillNoDamageNotify`, Ref `Zc_Use_Skill`.

## Cast and rejection

- **`013E`, 24 bytes.** `PACKET_ZC_USESKILL_ACK` has source/target u32@2/@6, cells u16@10/@12, skill u16@14, element u32@16 and cast delay u32@20. `clif_skillcasting` emits destination zero for a position target, normalizes the element, and sends the disguised source ID to SELF when applicable. Client `HandleSkillCastAck`, Ref `Zc_useskill_ack`.
- **`01B9`, 6 bytes.** `PACKET_ZC_DISPEL` contains actor u32@2. `clif_skillcastcancel` sends AREA. The receiver resolves an actor and owns cast-bar, casting-effect and motion cancellation. Client `HandleSkillCastCancel`, Ref `Zc_Dispel`.
- **`0110`, 10 bytes.** `PACKET_ZC_ACK_TOUSESKILL` has skill u16@2, reason value s16@4, item ID u16@6, result u8@8 and cause u8@9. `clif_skill_fail` sends result zero to SELF. It can suppress messages via server configuration, including interval, Snatcher and Poison cases. `src/map/skill.cpp` passes quantity and item ID separately for `USESKILL_FAIL_NEED_ITEM`. The selected client currently reads u32@4 and sends it to the legacy Ref reason resolver. Split those fields before deciding presentation for selected failure causes. Preserve compatibility for a received nonzero result and the existing motion-release check. Client `HandleSkillFailAck`, Ref `Zc_Ack_Touseskill`.

## Skill units and their messages

- **`011F`, 16 bytes.** `clif_getareachar_skillunit` writes the selected fixed frame manually using `clif_packetdb.hpp` length 16. It writes unit and creator u32@2/@6, cells as 16-bit words@10/@12, job u8@14 and visibility u8@15. The unit cells originate as signed map coordinates. The sender substitutes the dummy unit ID for a hidden trap or the nonrepresentative ranged unit. It skips guild auras and selects ensemble variants before encoding the job. The client compatibility path explicitly starts with visibility 1, matching Ref `Zc_Skill_Entry`, and the receiver's trap ownership logic can refine it. Review the dummy-job and reveal lifecycle together before changing that byte handling. Later `08C7`, `099F` and `09CA` layouts are outside the selected emitter branch.
- **`01C9`, 97 bytes.** `clif_graffiti` emits `packet_graffiti_entry` when the resolved job is Graffiti. Unit/creator u32@2/@6, cells s16@10/@12, job u8@14, visibility u8@15, message-present u8@16 and text bytes@17–96. The selected emitter sets both flags to 1. Review the message-present and no-message client paths in `HandleSkillUnitSet2` against Ref `Zc_Skill_Entry2`. Preserve bounded text and unit replacement/removal.
- **`01AC`, 6 bytes.** `clif_skillunit_update` sends the unit u32@2 to AREA for Ankle Snare trigger. There is no duration field. Ref `Zc_Skill_Update` and `HandleSkillUpdate` dispatch message 119 for unit jobs 139–153. Verify reveal/trigger semantics and the boundary jobs. Establish duration from the owning skill/effect lifecycle, with the server deletion event as a separate observation.
- **`0120`, 6 bytes.** `clif_skill_delunit` sends the unit u32@2 to AREA. `clif_clearchar_skillunit` sends the same identity to SELF when a viewer loses the unit. Ice Wall has separate map-cell updates. Client `HandleSkillDisappear` removes the unit from the world. Verify repeated and unknown removals, effect detachment and unit-only identity resolution.
- **`0191`, 86 bytes.** `clif_talkiebox` emits unit u32@2 and 80 text bytes@6 to AREA. `HandleTalkboxChatContents` forwards text to the resolved unit via message 7. Verify bounded text and the owner/lifetime of the resulting presentation.
