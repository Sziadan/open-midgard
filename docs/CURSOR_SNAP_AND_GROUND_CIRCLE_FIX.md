Added a ground-overlay texture preset that retains mode0 shading and requests clamp. Modern stage state now records D3DTSS_ADDRESS. Vulkan creates/caches samplers with address mode in the key; D3D11 includes clamp in its existing sampler descriptor key; D3D12 uses a separate clamped static-sampler root signature and distinguishes it in the pipeline cache. The legacy backend passes the same state through. Other texture presets explicitly restore wrap, preserving tiled terrain/effects. This does not clamp vertices' UVs, which would distort interpolated texture coordinates on boundary tiles.
